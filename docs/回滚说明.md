# 版本与回滚说明（M57）

## 版本策略
- **老版本 v1.0.0**：思维导图功能之前的状态（tag `v1.0.0`，分支 `release/old-v1`，对应提交 `7ac8bf0`）。
- **新版本 v1.1.0**：思维导图功能之后的状态（完成后打 tag `v1.1.0`，继续在 `main` 分支开发）。
- 每次发布前打一个 tag（`v1.0.0`、`v1.1.0`……），回滚 = `git checkout` 到对应的 tag 或老分支。

## 常用命令

```bash
# 1. 查看所有版本
git tag

# 2. 回滚到老版本（例如新版本出 bug）
git checkout v1.0.0            # 或 git checkout release/old-v1
npm.cmd run content            # 重新生成内容数据
npm.cmd run build              # 重新构建
# 本地预览：node node_modules/vite/bin/vite.js preview --port 4173 --host 127.0.0.1

# 3. 回到新版本继续开发
git checkout main

# 4. 新建发布版本
git tag v1.2.0                 # 在 main 打新 tag
```

## 回滚注意
- 回滚前先确认工作区干净（`git status` 无改动）。
- 回滚后 `content/index.json` 等数据文件随 build 重新生成，无需手动处理。
- `docs/内容缺口清单.md` 为项目记录文档，回滚不影响。
