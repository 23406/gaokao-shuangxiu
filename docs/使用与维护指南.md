# 使用与维护指南

本文档面向**站长本人**（小白友好版），讲清楚三件事：怎么用、怎么改内容、怎么上线。

## 一、日常使用

### 本地跑起来

```bash
npm install      # 第一次才需要
npm run dev      # 开发模式 → 浏览器打开 http://localhost:5173
```

### 看构建版（模拟线上效果）

```bash
npm run build
npm run preview  # → http://localhost:4173
```

## 二、内容怎么维护（核心技能）

**全站内容 = `content/` 目录下的 Markdown 文件，目录结构就是知识树结构。**

| 你想做的事 | 操作 |
| --- | --- |
| 改一个知识点的错误 | 编辑对应 `.md`，改完 `npm run content` 检查无警告 |
| 加一道例题 | 在对应分支的 `examples/` 目录新建 `.md`（格式见 `content/_schema.md`） |
| 加一个分类 | 新建目录 + `_index.md`（frontmatter 写 `title` 和 `desc`） |
| 把内容标为"已复核" | 把 frontmatter 的 `status: draft` 改成 `status: reviewed`（树上的"草稿"角标会消失） |
| 删除内容 | 删掉对应文件/目录即可（构建自动更新） |

**改完三步走**：`npm run content`（无 `[warn]`）→ `npm run build`（成功）→ `git push`（线上自动更新）。

### 例题格式速记

```markdown
---
title: 标题
type: example          # 知识点 knowledge / 例题 example / 口诀卡 mnemonic
status: draft          # 草稿；复核后改 reviewed
source: 自编           # 真题写"2024新课标Ⅰ卷·第X题"，自编写"自编"
applicability: 选填专用  # 邪修适用范围（有邪修必填）
risk: 风险提示          # 邪修风险（有邪修必填）
fit: [适用特征1, 适用特征2]  # 有邪修必填
---
## 题目
...
## 标准解法
...
## 邪修解法      # 没有邪修就删掉这节，页面自动不显示
```

公式：`$x^2$` 行内、`$$...$$` 独立；化学式 `\ce{H2O}`。

## 三、上线部署（等你决定）

你之前选择"先本地跑，部署以后再说"，想上线时按下面做：

### 方案 A：腾讯云 EdgeOne Pages（推荐，免费+免备案+国内快）

1. 注册腾讯云账号并实名（免费）；
2. 建 GitHub 仓库，推代码：
   ```bash
   git remote add origin https://github.com/你的用户名/gaokao-shuangxiu.git
   git push -u origin main
   ```
3. **改一处**：`src/config.ts` 里 `GITHUB_REPO = '你的用户名/gaokao-shuangxiu'`（否则纠错按钮指向不存在的仓库）；
4. 打开 [EdgeOne Pages 控制台](https://edgeone.cloud.tencent.com/pages) → 创建项目 → 连接 GitHub 仓库 → 构建命令 `npm run build`、输出目录 `dist`；
5. 等第一次构建完成，得到一个 `xxx.edgeone.app` 域名，分享给同学开冲。

### 方案 B：GitHub Pages（备份方案）

仓库 Settings → Pages → Source 选 "GitHub Actions"（仓库已带 `.github/workflows/deploy.yml`），push 即自动部署。

## 四、常见问题

| 问题 | 解决 |
| --- | --- |
| 改完内容页面没变化 | 先 `npm run content` 再刷新；开发模式会自动重启 |
| `[warn]` 警告 | 按警告提示补 `risk`/`applicability`/`fit` 或 `## 标准解法` |
| 收藏笔记丢了 | 只存在本机浏览器，清缓存前先到「我的」页面导出 JSON |
| 公式显示不对 | 检查 `$` 是否成对；化学式用 `\ce{...}` 要加 mhchem 支持的写法 |
| 想加图片 | 图片放 `public/img/`，Markdown 里写 `![](./img/xxx.png)`（目前以文字+公式为主） |
