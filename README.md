## 📖 这是个什么站

高考双修是一份**敢把"野路子"也写出来的高考复习资料**：数、理、化、生四科知识导图，外加一份跨科备考指南。全站 **445 个知识节点、222 道例题、335 条搜索索引**，覆盖新高考（新课标卷）主流考点。

每个例题都有左右两栏对照——

- **标准解法**：按部就班、考试能拿分的那种；
- **邪修速解**：选填题的秒杀套路，但绝不教"歪门邪道"——每一招都强制附带**适用特征 + 风险提示**，你先核对条件再用，考不到条件的邪修宁可不用。

> 让卖课的干不下去 😈 —— 本站所有内容免费、开源、可 PR 共建。

## 💻 本地部署

需要 Node.js 18+（推荐 20/22）。

```bash
npm install       # 安装依赖
npm run dev       # 本地开发：http://localhost:5173（热更新）
npm run build     # 生产构建：dist/ 目录（自动跑内容管线 + 质量闸门）
npm run preview   # 预览构建产物：http://localhost:4173
npm run smoke     # 数据层冒烟测试（内容/公式/链接，43 项断言）
npm run e2e       # 浏览器端到端测试（需先 build+preview，首次自动用 Chromium）
```

`dev` 和 `build` 都会先自动运行内容管线（Markdown → 知识树 JSON + 节点 HTML + 搜索索引），管线内置质量闸门：**断链 / KaTeX 公式错误会让构建直接失败**。

## 🧩 技术栈

Vite + Vue 3 + TypeScript + vue-router（**hash 路由**，静态托管零配置）+ Markdown 内容管线 + KaTeX（公式离线渲染）+ Fuse.js（全文搜索）。**零后端、零数据库、零追踪**，整个站点只是一堆静态文件，任何人都可以 fork 下来自己跑。

## 📝 内容怎么加 / 改

1. 在 `content/` 下新建或修改 Markdown（格式见 `content/_schema.md`）。
2. 本地 `npm run build` 确认内容管线通过（无断链、无 KaTeX 错误）。
3. 本地 `npm run build`，然后把构建产物 `dist/` 更新到 `gh-pages` 分支（站点从该分支发布，更新自动生效）。
