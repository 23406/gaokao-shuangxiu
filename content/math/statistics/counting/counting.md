# 计数原理与排列组合

## 两大原理

- **分类加法计数原理**："要么…要么…"→ 相加（互斥）；
- **分步乘法计数原理**："先…再…"→ 相乘（独立）。

## 排列与组合

- 排列：$A_n^m=\dfrac{n!}{(n-m)!}$（有序）；组合：$C_n^m=\dfrac{n!}{m!(n-m)!}$（无序）；
- 性质：$C_n^m=C_n^{n-m}$，$C_n^m+C_n^{m+1}=C_{n+1}^{m+1}$（杨辉三角）。

## 常用解题模型

| 模型 | 方法 | 例 |
| --- | --- | --- |
| 相邻问题 | **捆绑法**：捆成一个元素再排 | 3男3女排一排，男生相邻 |
| 不相邻问题 | **插空法**：先排其余，再插空 | 3男3女排一排，女生不相邻 |
| 定序问题 | 除序法 | n 个元素中 m 个顺序固定，$A_n^n/A_m^m$ |
| 分组分配 | 先分组再分配，均匀分组要除序 | 4人分2组每组2人：$\dfrac{C_4^2C_2^2}{A_2^2}$ |
| 特殊元素优先 | 特殊位置/元素先排 | 0 不能做首位 |
| 间接法 | 总数 - 反面 | "至少有一个"型 |

## 二项式定理

$$
(a+b)^n=\sum_{k=0}^{n}C_n^k a^{n-k}b^k
$$

- 通项：$T_{k+1}=C_n^k a^{n-k}b^k$；
- 系数和：令 $a=b=1$；$a=1,b=-1$ 得奇偶项系数差；
- 求指定项（常数项/$x^m$ 项）：令 $k$ 使指数满足条件。

## 邪修提示

- 选填计数：**小数据直接枚举**（$n\le4$ 时画树状图/列表比套公式快）；
- "至少"型优先**间接法**（总数−反面）；
- 二项式求系数和/指定项：代入法 + 通项公式，都是机械操作；
- 风险：计数题最容易**重复计数**（分组没除序、分类不互斥），算完用小数据验证。
