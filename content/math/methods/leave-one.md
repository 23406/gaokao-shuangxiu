# ⚡ 邪修·留一代一

> **适用特征**：求**过曲线上一点**的切线方程（圆/椭圆/双曲线/抛物线）；点坐标已给出且在曲线上。
>
> **风险提示**：点必须在曲线上；过曲线**外**一点引切线不能直接用；大题需要推导过程时不可直接写结论。

## 心法

曲线方程"留一代一"：平方项 $x^2\to x_0x$，$y^2\to y_0y$；一次项 $x\to\dfrac{x+x_0}{2}$，$y\to\dfrac{y+y_0}{2}$。

## 全家桶公式

| 曲线 | 上一点 $(x_0,y_0)$ 处的切线 |
| --- | --- |
| $x^2+y^2=r^2$ | $x_0x+y_0y=r^2$ |
| $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$（椭圆） | $\dfrac{x_0x}{a^2}+\dfrac{y_0y}{b^2}=1$ |
| $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$（双曲线） | $\dfrac{x_0x}{a^2}-\dfrac{y_0y}{b^2}=1$ |
| $y^2=2px$（抛物线） | $y_0y=p(x+x_0)$ |
| $(x-a)^2+(y-b)^2=r^2$ | $(x_0-a)(x-a)+(y_0-b)(y-b)=r^2$ |

## 为什么成立

切线是曲线的**一阶近似**：对 $x^2+y^2=r^2$ 两边微分得 $2x\,dx+2y\,dy=0$，在 $(x_0,y_0)$ 处斜率 $k=-\dfrac{x_0}{y_0}$，切线方程整理即 $x_0x+y_0y=r^2$。所以"留一代一"不是巧合，是微分的影子。
