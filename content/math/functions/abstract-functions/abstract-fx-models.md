# 抽象函数·特征方程配模型（仅选填）

抽象函数题只给运算法则（如 $f(x+y)=f(x)+f(y)$），不给解析式。**选填**中可直接把函数"猜"成满足该法则的最简函数（模型），再用题目给的数值把参数定出来——因为正确结论对所有满足条件的函数都成立，模型算出的结论就是答案。

## 五大基本模型（背表）

| 给的条件（特征方程） | 对应模型 | 说明 |
| --- | --- | --- |
| $f(x+y)=f(x)+f(y)$ | $f(x)=kx$（正比型） | 柯西方程，线性解 |
| $f(x+y)=f(x)\cdot f(y)$ | $f(x)=a^x$（指数型，$a>0$） | 必有 $f(0)=1$ |
| $f(xy)=f(x)+f(y)$ | $f(x)=\log_a x$（对数型） | 定义域 $x>0$，$f(1)=0$ |
| $f(xy)=f(x)\cdot f(y)$ | $f(x)=x^{\alpha}$（幂型） | 必有 $f(1)=1$ |
| $f(x+y)=f(x)\cdot f(y)+f(x)+f(y)$ | $f(x)=a^x-1$（构造型） | 两边 $+1$ 化为 $f(x)+1$ 的指数型 |
| $f(x+y)=f(x)+f(y)+c$ | $f(x)=kx-c$（一次型） | 令 $g(x)=f(x)+c$ 化为正比型；如 $f(x+y)=f(x)+f(y)+3$ ⇒ $f(x)=kx-3$ |

## 周期 / 对称类（另表）

| 给的条件 | 结论 |
| --- | --- |
| $f(x+a)=-f(x)$ | 周期 $2a$ |
| $f(x+a)=\dfrac{1}{f(x)}$ | 周期 $2a$（$f(x)\ne0$） |
| $f(x+a)=\dfrac{1-f(x)}{1+f(x)}$ | 周期 $4a$ |
| $f(a+x)=f(a-x)$ | 对称轴 $x=a$ |
| $f(a+x)+f(a-x)=2b$ | 中心对称点 $(a,b)$ |

## 三步用法

1. **读法则 → 对表选模型**：加法→正比型、加法指数→指数型、乘法对数→对数型……先确定"型"；
2. **定参**：把题给的数值代入（如 $f(2)=4$ ⇒ 正比型 $k=2$；指数型 $a^2=4\Rightarrow a=2$ 即 $f(x)=2^x$）；
3. **带入问项快算**：问 $f(2024)$、$f(-3)$、单调性、奇偶性，直接按模型口算。

## 为什么可以这么用（选填的安全性）

- 每个模型都是对应特征方程的**一个特解**（代入可验），选填题只要找到**一个**满足全部条件的函数、用它得到唯一确定结论，这个结论就必然普遍成立（结论是"所有满足条件的函数共同具有"时）；
- 更大类函数（如 $f(x+y)=f(x)+f(y)$ 的唯一连续/单调解就是 $kx$）在中学（连续/单调假设下）即通解——模型就是"原型函数"；
- **反用**：若题目问"可能/不一定成立"，构造模型找到反例即可否决某选项。

## 风险

- 模型必须**严格满足题目全部条件**（定义域、单调、奇偶等），缺一个条件就可能选到错误模型；
- "求最大值/最小值/判断一定成立"类：模型得数即答案；但**"存在性"问题**（如"是否存在 $a$ 使…"）用模型只能验证"可能"，不能证明"全部"；
- 解答题禁止只写模型（无通解证明不给分）——但可**用模型先猜答案**，再用递推/放缩补证明；
- 别把"周期类"套到"单调类"：先判断给的是**运算法则**（映射关系）还是**平移规律**（周期/对称）。
