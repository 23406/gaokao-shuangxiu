# 隐零点

> **适用场景**：函数 $f'(x)$ 的零点 $x_0$ **无法求出来**（超越方程），但要利用"$f'(x_0)=0$"这个关系证明极值 > 0（或 < 0）。导数压轴第二/三问的"设而不求"思想。

## 核心思想

**不求 $x_0$ 的值，只利用 $x_0$ 满足的方程**——设 $f'(x_0)=0$，反解出某个量（如 $\mathrm e^{x_0}=\dfrac1{x_0}$），代入极值表达式消元。

## 标准四步

1. **证存在**：证明 $f'(x)$ 在区间内单调（$f''(x)$ 定号），且两端点异号 ⇒ 存在唯一 $x_0$；
2. **设零点**：设 $f'(x_0)=0$，写出代数关系（如 $\mathrm e^{x_0}=\dfrac1{x_0}$）；
3. **消元**：极值 $f(x_0)$ 代入关系式，把所有"坏项"换掉；
4. **定符号**：用基本不等式/放缩证明 $f(x_0)>0$（注意 $x_0$ 的范围，如 $0<x_0<1$）。

## 常见隐藏关系（背住）

| 方程 | 常用消元结论 |
| --- | --- |
| $\mathrm e^{x_0}=\dfrac1{x_0}$ | $\ln x_0=-x_0$（两边取对数） |
| $x_0\mathrm e^{x_0}=1$ | $x_0+\ln x_0=0$ |
| $\ln x_0=\dfrac1{x_0}$ | 无简单形式，但 $x_0>1$ 的范围很有用 |
| $\mathrm e^{x_0}=x_0+2$ | 就代入消元，不化简 |

**价值提醒**：消元后通常出现"对勾/基本不等式"结构（如 $x_0+\dfrac1{x_0}>2$），这是命题人埋好的路标。

## 兄弟招：双零点范围估计

若 $f'(x)$ 有两个零点 $x_1<x_2$：先证 $x_1$、$x_2$ 落在哪个区间（代入端点值看符号），再分别利用关系消元——"先估区间，再用关系"。
