# 极值点偏移

> **适用场景**：函数 $f(x)$ 有唯一极值点 $x_0$，且 $f(x_1)=f(x_2)$（$x_1\neq x_2$），证明 $x_1+x_2>2x_0$（或 $<2x_0$）。导数压轴第三问的标准套路。

## 什么是"偏移"

- 若 $x_1+x_2=2x_0$：极值点居中（不偏移）；
- $x_1+x_2>2x_0$：中点偏右 → 函数右侧"更胖"，称极值点**左偏**；
- $x_1+x_2<2x_0$：极值点**右偏**。

（方向判断：取一对特殊值 $x_0\pm\delta$ 算 $f$ 值——**哪边下降更慢（"更胖"），中点就偏哪边**；等价地：哪边更陡，那边的交点离 $x_0$ 越近。）

## 标准解法：对称构造法（背流程）

设 $x_1<x_0<x_2$，要证 $x_1+x_2>2x_0$：

1. **对称函数**：构造 $g(x)=f(x)-f(2x_0-x)$，$x\in$（$x_0$ 的左侧区间）；
2. **判单调**：求 $g'(x)$，证明 $g(x)$ 单调（目标得到 $g(x)<0$ 或 $>0$）；
3. **平移还原**：由 $g(x_1)$ 的符号推出 $f(x_1)$ 与 $f(2x_0-x_1)$ 的大小；
4. **用单调性**：$f(x_2)=f(x_1)$ 与 $f(2x_0-x_1)$ 比大小，得出 $x_2$ 与 $2x_0-x_1$ 的关系。

> 口诀：**"对称构造，定单调，比大小，还原偏移方向"**。四步缺一不可。

## 方法二：比值换元（其他双变量不等式）

含 $x_1x_2$、$x_1+x_2$ 的代数式：由 $f(x_1)=f(x_2)$ 引入 $t=\dfrac{x_2}{x_1}$（$t>1$），把 $x_1,x_2$ 都用 $t$ 表示，化为单变量函数——**一切双变量问题先想换元**。

## 判断偏移方向的"快检法"（选填/验算）

取 $x_0$ 两侧各一个对称点，比较 $f(x_0-\delta)$ 与 $f(x_0+\delta)$ 大小即可定性（**以极大值点为例**，极小值点方向相反）：

- 左侧更大（左支下降更慢、更"胖"） → 中点偏左（$x_1+x_2<2x_0$）；
- 右侧更大 → 中点偏右（$x_1+x_2>2x_0$）。

验证：$f(x)=xe^{-x}$（$x_0=1$），$f(0.5)=0.303<f(1.5)=0.335$（右侧更大），解 $f(x)=0.303$ 得 $x_1\approx0.5$、$x_2\approx1.75$，$x_1+x_2\approx2.25>2$，中点偏右 ✓
