# 导数

## 基本求导公式（必背）

- $(x^n)'=nx^{n-1}$，$(a^x)'=a^x\ln a$，$(\log_a x)'=\dfrac{1}{x\ln a}$
- $(\sin x)'=\cos x$，$(\cos x)'=-\sin x$
- 四则：$(u\pm v)'=u'\pm v'$，$(uv)'=u'v+uv'$，$\left(\dfrac{u}{v}\right)'=\dfrac{u'v-uv'}{v^2}$
- 复合函数：$[f(g(x))]'=f'(g(x))\cdot g'(x)$（链式法则）

## 单调性判定

$f'(x)>0$（在区间内）→ $f(x)$ 单调递增；$f'(x)<0$ → 单调递减。

**含参讨论的标准动作**（大题模板）：

1. 求定义域；
2. 求 $f'(x)$，通分、因式分解（尽量提公因式）；
3. 讨论参数使 $f'(x)$ 的符号发生变化的临界点（如 $\ln$ 的定义域边界、二次函数判别式、两根大小关系）；
4. 列表写单调区间，注意"区间端点"处理。

## 极值与最值

- 极值点必要条件：$f'(x_0)=0$（还要检验左右符号是否变号！）；
- 最值：比较极值与端点值；
- 恒成立 $f(x)\ge 0$ ↔ 最小值 $\ge 0$；$f(x)\le 0$ ↔ 最大值 $\le 0$；
- 分离参数法：$a\le g(x)$ 恒成立 ↔ $a\le g(x)_{\min}$。

## 高考高频题型地图

| 题型 | 关键词 | 邪修 |
| --- | --- | --- |
| 切线问题 | "切线过点/公切线" | 斜率 = 导数值，选填直接套 |
| 单调性讨论 | "在区间上单调" | 端点代入检验（端点效应） |
| 恒成立求参 | "恒成立/存在" | 端点效应 + 分离参数心算 |
| 零点个数 | "恰有 n 个零点" | 图像法：$f(x)=0$ 变形为 $g(x)=h(x)$ 数交点 |
| 极值问题 | "极大值/极小值" | 特殊点代入排除 |

## 易错点

1. 极值点 ≠ 驻点：$f'(x_0)=0$ 是必要不充分条件；
2. 求单调区间要先写定义域，对数真数 $>0$ 的约束别丢；
3. "$f(x)$ 在 $(a,b)$ 单调递增"推出 $f'(x)\ge0$（不是 $>0$），反之要检验 $f'(x)\equiv0$ 的常函数退化情形。
