# 函数概念与性质

## 概念三要素

**定义域、对应关系、值域**。高考对定义域的考察点：

1. 分式分母 $\neq 0$；偶次根号内 $\ge 0$；对数真数 $>0$；
2. 复合函数定义域："内层值域 ⊆ 外层定义域"；
3. 抽象函数定义域：用同一个 $x$ 满足所有条件。

## 单调性

- 定义法：任取 $x_1<x_2$，判断 $f(x_1)-f(x_2)$ 的符号；
- 导数法：$f'(x)>0$（严格）单调递增；
- 复合函数："同增异减"；
- 常用结论：奇函数在对称区间上单调性**相同**，偶函数在对称区间上单调性**相反**。

## 奇偶性

- 定义：$f(-x)=f(x)$ 偶；$f(-x)=-f(x)$ 奇；先看定义域是否关于原点对称；
- 常用结论：
  - 奇函数 $f(0)=0$（若 0 在定义域内）；
  - 奇×奇=偶，奇×偶=奇，偶×偶=偶；
  - $f(x)+f(-x)$ 恒为偶函数，$f(x)-f(-x)$ 恒为奇函数；
  - 奇函数平移：$f(x-a)$ 关于 $(a,0)$ 对称；偶函数平移：$f(x-a)$ 关于 $x=a$ 对称。

## 周期性

- 定义：存在非零常数 $T$，$f(x+T)=f(x)$ 恒成立；
- 常见结论：$f(x+a)=f(x)$ → 周期 $a$；$f(x+a)=-f(x)$ 或 $f(x+a)=\dfrac{1}{f(x)}$ → 周期 $2a$；
- 对称性 + 周期性：两条对称轴/两个对称中心/一条对称轴+一个对称中心，都能推出周期性（两对称轴距离 $2|a-b|$ 为周期）。

## 抽象函数常见模型（见到直接联想）

| 条件 | 联想模型 |
| --- | --- |
| $f(x+y)=f(x)+f(y)$ | 正比例型 $f(x)=kx$ |
| $f(x+y)=f(x)f(y)$ | 指数型 $f(x)=a^x$ |
| $f(xy)=f(x)+f(y)$ | 对数型 $f(x)=\log_a x$ |
| $f(xy)=f(x)f(y)$ | 幂型 $f(x)=x^\alpha$ |
| $f(x+y)=\dfrac{f(x)+f(y)}{1-f(x)f(y)}$ | 正切型 $f(x)=\tan x$ |

**邪修提示**：抽象函数选填题（尤其"一定正确的是"），优先构造满足条件的特殊函数代入排除——正比例/指数/对数型轮着试，比硬推快 10 倍（见例题）。

## 易错点

1. 求单调区间前先求定义域，区间必须落在定义域内；
2. 判断奇偶性必须先检查定义域对称性；
3. "$f(x)$ 在 $[a,b]$ 上单调"与"单调区间为 $[a,b]$"含义不同（前者是子集）。
