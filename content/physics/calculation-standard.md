# 物理计算题规范与抢分

> 物理大题按**步骤给分**：结果错了，过程照样拿分；过程混乱，结果对了也危险。以下套路是阅卷老师的"采分点地图"。

## 通用解题四步（每题必走）

1. **审题画图**：受力图/运动图/过程图——图上标已知量；
2. **选对象列原理式**：对谁？用什么定理/定律？（牛顿第二定律/动能定理/动量守恒/能量守恒/法拉第定律）；
3. **列方程代数据**：先写字母式，再代入数值（**不写字母式直接代数字 = 少一半步骤分**）；
4. **结论与讨论**：写结果带单位；必要时按**字母参数分情况**讨论（如电荷正负、多解取舍）。

## 分题型模板

**动力学综合**：

- 第一问：受力分析 → $F_{合}=ma$ → 运动学公式；
- 多过程：**分段**，每段重新受力分析，衔接点速度是"桥"；
- 板块/传送带：先判断摩擦方向，再写运动学，共速条件列方程。

**能量动量**：

- 含碰撞 → 动量守恒（先写"系统合外力为零"）；
- 含摩擦生热 → $Q=f s_{相对}$；
- 弹簧最大压缩 → 共速瞬间，动量守恒 + 能量守恒联立。

**电磁感应**：

- 棒切割：$E=BLv$ → $I=\dfrac{E}{R}$ → $F_{安}=BIL$ → 牛顿第二定律；
- 求电量：$q=\dfrac{\Delta\Phi}{R}$；求热量：能量守恒（克服安培力做功）。

**带电粒子**：

- 电场中：类平抛分解；磁场中：$r=\dfrac{mv}{qB}$ + 几何关系；
- 组合场：分段算，**边界速度**是衔接量。

## 常见失分点（阅卷实况）

1. 缺"研究对象"表述（"对 A 物体，由动能定理得"——这句不能省）；
2. 矢量方向没说明（"以…为正方向"）；
3. 计算结果不写单位；
4. 字母式未化简就代数字（保留中间量符号更稳）；
5. 讨论缺失：$g$ 取 10 还是 9.8、$\sqrt{}$ 正负取舍、临界是否取等号。

## 压轴题抢分策略（时间不够时）

- 第一问通常简单（送分），**先做第一问**；
- 后几问写"原理式"：把 $F=ma$、动量守恒式、能量式摆上，能拿"列式分"；
- 设而不求：设出未知量（如 $v_{共}$），写出关键方程——即使算不出也能拿一半；
- 检查"量纲"：结果单位不对=白算，回查公式。

## 邪修提示（选填/检验）

- 结果检验：**量纲法**（$F$ 单位必须是 N）、极限法（$m\to0$ 或 $\theta\to90°$ 看趋势）、特殊值代入；
- 大题写完用"能量守恒"验算一遍结果（动量+能量双保险）；
- 风险：别在计算题用"二级结论"当推导过程——**结论只能加速，不能替代步骤**。
