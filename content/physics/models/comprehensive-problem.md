# 物理综合大题·多过程切入点与思维范式

新高考物理压轴的特点是**多对象 × 多过程 × 多规律**（例如 2026 年河北卷压轴的力学+电磁串珠模型）。解题的关键不是"会算哪一步"，而是**先看清过程链，再逐段选规律**。

## 三步拆解题面

**第一步：读题画"过程链图"**——把题面翻译成一条时间线：

> 过程 1（加速）→ 过程 2（碰撞）→ 过程 3（在板上滑行）→ 过程 4（离开磁场/滑出）

每个过程标四件事：**对象**（哪个物体）、**初末状态**（速度/位置/能量）、**受力或场**、**边界特征**（共速？恰好脱离？最大高度？）。

**第二步：每个过程只选 1～2 个主规律**（避免撒网）：

| 过程特征 | 首选规律 | 补充 |
| --- | --- | --- |
| 匀变速/受恒力 | 牛顿第二定律 + 运动学 | 动能定理替代更省力 |
| 碰撞/爆炸/连接 | 动量守恒 | 再配能量（弹性/非弹性区分） |
| 电磁感应 单棒 | 动量定理（安培力冲量） | 能量守恒 + $F=BIl$ 定律 |
| 圆周运动 | 牛顿第二定律（向心力） | 能量守恒求速度 |
| 平抛/类平抛 | 运动学分解 | 动能定理备选 |

**第三步：找"连接点"**——过程的边界状态就是隐含方程：

- 共速时刻（板块、弹簧、连接体）：$v_A=v_B$；
- 恰好脱离/恰好相碰：位移相同或距离转零（例如追及末态 $s_A-s_B=L$）；
- 最大高度/最大压缩量：对应速度相等（动能最小、势能最大）；
- 恰好离开轨道：$N=0$（重力/弹力提供向心力临界）；
- 安培力与外力平衡：$F_{\text{恒}}=F_{\text{安}}(v)$ → 求收尾速度。

## 答题思维四步（怎么想、怎么写）

1. **先全局后局部**：先判断**整体是否守恒**（动量守恒/机械能守恒/能量守恒），守恒优先用守恒；
2. **状态量 vs 过程量**：位置、速度、高度用状态方程（能量/运动学）；功、冲量、位移用过程量（$W$、$I$、$s$、$Q$）——"每个物理量只写一次"；
3. **下标与编号**：每个过程的速度（$v_1$、$v_2$、$v_2'$）、每个物体的质量（$m_A$、$m_B$）标清，杜绝"$v$"混用丢分；
4. **检验三看**：量纲（单位）×极限图景（速度趋 0、时间趋∞ 时合不合理）×选项/常识复核。

## 高频"组合拳"（压轴常客）

| 组合 | 主线 |
| --- | --- |
| 板块 / 传送带 + 碰撞 | 动量守恒 + 能量（摩擦产热 $Q=\mu mg s_{\text{相对}}$） |
| 弹簧连接体 | 动量守恒 + 能量（压缩最大=共速，$E_p=\dfrac12\mu v_{\text{相对}}^2$，$\mu$ 为折合质量） |
| 圆周 + 平抛 | 能量求速度 → 平抛运动学分解 |
| 单棒 + 磁场 + 电容/外电阻 | 动量定理累计冲量；$BLv$ 电动势 + $F=BIl=ma$ 联立微分关系 |
| 多物多过程 | 按过程**分别**列守恒（动量不守恒时，某段可能守恒） |

## 示范（多过程力学综合，思路示范）

> 光滑水平面上质量为 $m_1$ 的小车以 $v_0$ 与质量 $m_2$ 的物块碰撞后共速；此后物块在小车上滑行，摩擦因数 $\mu$，问：碰撞后瞬间速度、物块相对小车滑行的最大位移（即共速时的相对位移）与系统产热。

**入口**：碰撞（瞬间、忽略摩擦）→ **动量守恒**：$m_1v_0=(m_1+m_2)u$ ⇒ 共速速度 $u=\dfrac{m_1v_0}{m_1+m_2}$；
**滑行过程**（能量）→ 系统初动能 $\dfrac12 m_1v_0^2$，末动能 $\dfrac12(m_1+m_2)u^2$，差值 = 摩擦产热 $Q=\mu m_2 g\,s_{\text{相对}}$ ⇒ $s_{\text{相对}}=\dfrac{Q}{\mu m_2 g}$（$Q$ 由动能差直接给，不必解牛二微分）。

**同一模型换问法**：若问"物块恰好滑出小车左端" → 边界条件 $s_{\text{相对}}=L$（板长）反解 $v_0$ 临界值——这就是"找到连接点"的威力：方程个数=过程个数+连接条件个数。

## 风险

- **守恒判错**（把"系统动量守恒"误用于地面参考系、非瞬时碰撞段）；
- **漏连接点**：几乎每道压轴的"卡点"都藏在连接条件里，读题时用笔圈出"恰好/刚好/最大/最小/共速"字样；
- **方程数不够**：未知数个数=方程个数才能解；数不齐先回题面找遗漏（通常是连接条件或某过程的能量/动量）；
- 若涉及**电磁**：感应电流方向、安培力朝反运动方向、$F$ 与 $v$ 的函数关系（$F=\dfrac{B^2l^2v}{R}$）要写清定方向。
