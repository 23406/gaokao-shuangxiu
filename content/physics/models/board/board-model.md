# ⚡ 模型·板块

> **适用特征**：滑块+长木板组合；判断能否共速、求相对位移/时间/生热。
>
> **风险提示**：先判断地面是否光滑、板与块摩擦系数是否相同；"共速后"可能一起减速也可能继续相对滑动（用共速时的加速度比较判别），大题必须分阶段讨论。

## 标准分析框架（四步）

1. **受力分析**：明确摩擦力方向（看相对运动趋势）；
2. **隔离求加速度**：块 $a_块=\mu g$，板 $a_板$ 由牛顿第二定律单独算；
3. **运动学衔接**：共速条件 $v_块=v_板$，解出共速时间 $t$；
4. **位移与能量**：$Q=\mu mg\cdot s_{相对}$，$s_{相对}=s_块-s_板$（同向）或相加（反向）。

## 常见二级结论（光滑地面，块有初速度 $v_0$ 放上静止木板）

- 共速速度：$v_{共}=\dfrac{m}{M+m}v_0$；
- 相对位移：$s_{相对}=\dfrac{Mv_0^2}{2\mu g(M+m)}$；
- 生热：$Q=\dfrac12\cdot\dfrac{Mm}{M+m}v_0^2$。

**推导（大题模板，选填可跳过）**：

1. 共速：系统水平动量守恒 $mv_0=(M+m)v_{共}\Rightarrow v_{共}=\dfrac{m}{M+m}v_0$；
2. 相对位移：能量守恒 $\mu mg\,s_{相对}=\dfrac12mv_0^2-\dfrac12(M+m)v_{共}^2$，把 $v_{共}$ 代入即得 $s_{相对}$ 与 $Q$；
3. 折合质量 $\dfrac{Mm}{M+m}$ 不是凭空来的——它就是"相对动能"里的等效质量：$\Delta E_k=\dfrac12\cdot\dfrac{Mm}{M+m}v_0^2$（动量守恒消元后自然出现）。

> ⚠ 大题严禁直接写 $v_{共}=\dfrac{m}{M+m}v_0$ 当推导——先写"系统水平方向动量守恒"这一句，再列式。

## 共速后的判别（易错点）

共速瞬间：

- 若 $\mu_块 mg \le \mu_{板地}(M+m)g$（块对板的最大静摩擦力不足以驱动板）→ 板基本不动，块单独滑行减速；
- 若 $\mu_块 mg > \mu_{板地}(M+m)g$ → 板被带动，共速后**一起**（匀）减速。判据即比较 $\mu_块$ 与 $\mu_{板地}\cdot\dfrac{M+m}{m}$。

**口诀**："共速先算加速度，谁的加速度大谁先停"。（若地面光滑 $\mu_{板地}=0$，则共速后恒一起运动。）

## 邪修提示

- 选填：直接套共速速度与生热公式（折合质量 $\dfrac{Mm}{M+m}$ 无处不在）；
- 问"多长时间达到共速"：$t=\dfrac{v_0}{\mu g}\cdot\dfrac{M}{M+m}$；
- 大题不会做到底：先写"$v_{共}$ 由动量守恒 $mv_0=(M+m)v_{共}$ 得"——这行就是分数。
