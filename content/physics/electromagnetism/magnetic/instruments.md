# 磁场应用仪器专题

> 五大仪器 = 三模型（匀速直线 / 圆周运动 / 定向堆积）+ 一份电压公式。

![](img/physics/mass-spectrometer.svg)

## 一、速度选择器（匀速直线）

**装置**：正交匀强电场 $E$（竖直）与匀强磁场 $B$（垂直纸面），让带电粒沿水平通过。

**条件**：$qvB=qE\Rightarrow v=\dfrac{E}{B}$

- 通过者是"刚好平衡"的粒子：合力为零 → 匀速直线；
- 与 $q$、$m$、电性**均无关**（凡是速度 $=E/B$ 的都直穿）；
- $v>E/B$ 的粒子：洛伦兹力大 → 向磁场力方向偏折；$v<E/B$ 反过来——**偏折方向由"谁大"决定**；
- 常与质谱仪串接：速度选择器洗出同速粒子 → 进入磁场偏转。

## 二、质谱仪（圆周运动）

**流程**：离子源 → 加速场 $U$：$qU=\tfrac12mv^2$ → 垂直射入匀强磁场 $B$：$r=\dfrac{mv}{qB}$。

合并两式：

$$r=\dfrac{1}{B}\sqrt{\dfrac{2mU}{q}}$$

- 同位素质量不同（$q$ 相同）→ 半径不同 → 打在感光片不同位置，实现分离；
- **$r\propto\sqrt{m}$**（$U,B,q$ 相同时），质量比 $1:2$ 的两种离子半径比 $1:\sqrt2$；
- 也可反求比荷 $\dfrac{q}{m}=\dfrac{2U}{B^2r^2}$ ——"质谱法测比荷"是主线考法。

## 三、回旋加速器（周期固定的圆周运动）

**结构**：两个 D 形盒（内为匀强磁场），盒间窄缝加交变电场。

**两条铁律**：

1. 粒子在磁场中周期 $T=\dfrac{2\pi m}{qB}$ **与速度无关** → 交变电场周期必须 = $T$，粒子才能"每次都赶上"加速；
2. 最大动能只由 D 盒半径 $R$ 决定：$E_{km}=\dfrac{q^2B^2R^2}{2m}$，**与加速电压 $U$ 无关**！

- 电压 $U$ 加倍 → 每次加速增量更大 → 所需加速次数 $n=\dfrac{E_{km}}{qU}$ 减半，但最终动能不变；
- 相对论效应：速度接近光速时 $m$ 增大、$T$ 变长、失去同步 → 故不能无限加速到任意大（高考选填只考"与电压无关"+周期匹配）。

## 四、霍尔效应（定向堆积）

**现象**：通电的半导体/导体板，置于垂直板面的磁场中，载流子受洛伦兹力偏转在板两侧堆积 → 产生横向电压 $U_H$。

**平衡推导**：载流子横向不再堆积时 $qvB=qE=U_H/a$（$a$ 横向宽度），又 $v=\dfrac{I}{nqS}$、$S=a\cdot d$（$d$ 为板厚，即磁场方向尺寸），代入：

$$U_H=\dfrac{BI}{nqd}$$

- 与板的长、宽**无关**，与板厚 $d$ 及载流子浓度 $n$ 成**反比**（这是"霍尔测磁场/测浓度"的根据）；
- **判极性**（必考）：用左手定则判断载流子偏转方向——正载流子积累一侧为正 $q$、负载流子积累的那一侧为**负**电位。同一电流磁场下，电子导电与空穴导电的电压极性**相反**；
- 霍尔元件测 $B$：固定 $I,n,q,d$ → $U_H\propto B$，标定后即磁强计。

## 五、电磁流量计 / 磁流体发电（Bvd 对）

**共同点**：导电流体横穿磁场，定向运动离子受洛伦兹力分离 → 感应电动势 $E=Bdv$（$d$ 为管道直径/极板间距）。

- 电磁流量计：$v=\dfrac{U}{Bd}$，流量 $Q=v\cdot\dfrac{\pi d^2}{4}=\dfrac{\pi dU}{4B}$；
- 磁流体发电：电动势 $\varepsilon=Bdv$，内阻由等离子体内阻给出；
- 与切割磁感线公式 $\varepsilon=BLv$ 同源，只是"导体"变成流动液体。

## 例题

### 例 1（选填）：质谱仪半径比

**题目**（自编）两种同位素离子带电量相同，先后经同一加速电场 $U$、进入同一匀强磁场 $B$ 偏转，打在感光板上。若两者质量比 $m_1:m_2=1:2$，则两轨迹半径比 $R_1:R_2$ 为？

**标准解法**：

由 $r=\dfrac{1}{B}\sqrt{\dfrac{2mU}{q}}$，$U,B,q$ 相同 → $r\propto\sqrt{m}$，故

$$\frac{R_1}{R_2}=\sqrt{\frac{m_1}{m_2}}=\frac{1}{\sqrt2}=\frac{\sqrt2}{2}$$

**点评**：① 先写出 $r$ 的合并式再比，比"两步代入"快且不易错；② 加"同一加速电压"是前提，两问中若换 $U$ 则不能直接比；③ 求"落点间距"记得乘 2（两半径之和/差）：$\Delta x=2|R_2-R_1|$。

### 例 2（选填）：回旋加速器判断

**题目**（自编）回旋加速器 D 形盒半径为 $R$、磁感应强度为 $B$，交变电压有效值 $U$ 恒定。下面说法正确的是：

A. 粒子获得的最大动能与 $U$ 无关

B. 增大 $U$，粒子获得的最大动能增大

C. 增大 $B$，粒子每次经过窄缝获得的动能增大

D. 交变电压周期应等于粒子周期的 2 倍

**标准解法**：

$E_{km}=\dfrac{q^2B^2R^2}{2m}$ 只含 $R,B,m,q$ → 与 $U$ **无关**，A 对 B 错。

每次经过窄缝加速 $\Delta E=qU$ 只与 $U$ 有关 → 增大 $B$ 不改变单次增量，C 错。

交变电场周期 = 粒子回旋周期 $T=\dfrac{2\pi m}{qB}$（每转一圈过缝两次、电压方向变两次），D 错。

**点评**：①"最大动能只由 D 盒半径决定"是送分点，但选项常把它和 $U$ 挂钩——抓住 $E_{km}$ 表达式中**没有 $U$** 即破；② 若问"加速次数"用 $n=\dfrac{E_{km}}{qU}$，$U$ 加倍、$n$ 减半；③ 周期同步条件要写"电场周期 = 粒子周期"，审题时注意"一半周期"的表述与图解法。

### 例 3（选填）：霍尔极性

**题目**（自编）一块半导体薄板，厚度 $d$（沿 $z$ 轴），电流沿 $x$ 方向（电子导电），外加匀强磁场沿 $z$ 方向。测得沿 $y$ 方向出现霍尔电压。下列说法正确的是：

A. 洛伦兹力使电子向 $+y$ 方向偏转，$+y$ 一侧电势较低

B. 洛伦兹力使电子向 $-y$ 方向偏转，$-y$ 一侧电势较低

C. 电压大小与板厚 $d$ 成正比

D. 若载流子换成带正电的空穴（电流、磁场均不变），霍尔电压极性不变

**标准解法**：

电流沿 $+x$，电子运动方向 $-x$：$F=q\vec v\times\vec B$，$q\vec v$ 与电流同向（$+x$），故电子受力沿 $\vec x\times\vec z=-\vec y$ → 电子向 $-y$ 偏转堆积，$-y$ 侧带负电、**电势较低**，A 错 B 对。

$U_H=\dfrac{BI}{nqd}\propto\dfrac1d$，与 $d$ 成反比，C 错。

空穴带正电（其"正电荷运动"方向即电流方向，$q\vec v$ 仍沿 $+x$、受力仍向 $-y$），但 $-y$ 侧积累的是**正电荷** → 极性与电子导电**相反**，D 错。

**点评**：① 判极性唯一动作：判**实际载流子**的偏转方向 + 其电性——注意 $q\vec v$ 对正/负载流子都沿电流方向，**受力方向相同**，区别只在积累的是正电还是负电；正负电荷判反是高频失分点；② $U\propto\frac{1}{d}$ 常被"板越厚电压越大"的直觉骗到；③ "换载流子电性、极性反转"直接从 $U_H=\frac{BI}{nqd}$ 里 $q$ 的符号看。

## 邪修提醒

- **一张表背下来**：速度选择（$v=E/B$ 直穿）、质谱（$r=\frac{mv}{qB}$ 分类）、回旋（$T$ 不随 $v$ 变 + $E_{km}$ 与 $U$ 无关）、霍尔（$U=\frac{BI}{nqd}$）、流量计（$U=Bdv$）——五个仪器五条式子，全部由 $qvB$ 一个力推出；
- 霍尔"厚度"是**磁场方向**的尺寸（不在画面里的那度），图中标注混乱时先找 $B$ 的方向；
- 速度选择器反向射入（从右向左、$v,E,B$ 不变）依然直穿——条件只由 $v$ 大小决定，方向必须与 $E,B$ 正交且合力为零（若题设 $v$ 斜射则不能直穿）。
