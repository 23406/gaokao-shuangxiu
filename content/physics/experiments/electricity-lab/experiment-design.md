# 电学实验设计与仪器选择

> 配合 [伏安法内接外接](/node/physics/experiments/electricity-lab/ammeter-connection)（内接/外接判断）与本目录其他实验卡使用。实验设计题的标准答题链：**定原理 → 选器材 → 定接法 → 画电路 → 数据/误差**。

## 一、滑动变阻器：限流 vs 分压

| | 限流接法 | 分压接法 |
|---|---|---|
| 接法 | 滑变与待测支路**串联**，滑片与一端引出 | 滑变**两端**接电源，滑片与一端引出并联支路（电压加在"滑片—端点"之间） |
| 调压范围 | $\dfrac{E R_x}{R_x+R}$ ~ $E$（调不到 0） | $0$ ~ $E$ |
| 调节特性 | $R\gg R_x$ 时范围宽、较均匀 | $R$ 较小时线性好、易调 |
| 功率 | 总电流小 | 滑变有"附加电流"，额定电流要求高 |
| 何时必选 | 无特殊要求、$R_x$ 合适 | ① 要求电压**从 0 开始**调节；② 需要**多组数据**描点；③ 测伏安特性曲线；④ $R_x$ 远大于滑变阻值 |
| 滑变阻值选择 | **$R$ 略大于 $R_x$**（或几倍） | **$R$ 取小**：$R\lesssim R_x$ 且额定电流足够 |

![](img/physics/circuit-limit-divider.svg)

**推导（调压范围）**：限流时 $U_x=\dfrac{ER_x}{R_x+R}$，$R$ 越大范围越宽；分压时滑片移到下端，$U_x=0$，移到上端，$U_x\approx E$（忽略滑变内阻）。

> 记法：**"要 0 就分压，多组数据就分压；负载大于滑变就分压"**；限流当选"不够 0、只求简单可靠"。

## 二、仪器选择四原则（背）

1. **安全**：各元件电流、电压不超量程/额定值；电源电动势 $\le$ 电压表量程。
2. **精确**：电表指针偏转**超过量程的 $\frac13$**（读数才有有效位数）；欧姆表指针在中值附近最准。
3. **方便**：量程适当、滑变调节顺滑（否则读数跳跃、描点稀疏）。
4. **匹配**（最易丢分）：滑变与接法匹配（分压选**小阻值**、限流选**较大阻值**）；电表内阻与接法匹配（大电阻内接、小电阻外接，见 [伏安法内接外接](/node/physics/experiments/electricity-lab/ammeter-connection)）。

**操作顺序**：**先估后选**——用粗略值估算最大电流 $I_{\max}$、最大电压 $U_{\max}$，再对应选量程；估算要写出来（大题中"选择并说出理由"按此格式）。

## 三、伏安法测电阻·设计题模板

以"测 $R_x$（小电阻，约 $5\sim10\,\Omega$）"为例：

1. **原理**：$R_x=\dfrac{U}{I}$，用伏安法；
2. **接法**：$R_x^2<R_AR_V$（$R_A=0.5\,\Omega,R_V=3000\,\Omega$，$\sqrt{R_AR_V}\approx38.7\,\Omega>R_x$）→ 外接（"小外偏小"）；
3. **滑变**：要求"电压从 0 起调、测 5 组数据"→ **分压**；滑变选阻值 **$\le R_x$**（如 $10\,\Omega$），额定电流按 $I\approx\dfrac{E}{R_{\min}}+\dfrac{U_x}{R_x}$ 估算；
4. **电路**：电源 $E$—开关 $S$—滑变（分压）-并联支路（电压表 — ($R_x$—电流表) 串）；
5. **数据**：列表 5 组 $(U,I)$，逐次算 $R$ 取平均，或作 $U$-$I$ 图取斜率；
6. **误差**：外接 → $R_{\text{测}}=\dfrac{U}{I_{\text{总}}}<R_{\text{真}}$（电压表分流，$I$ 偏大）。

## 四、测电源电动势 E 与内阻 r（伏安法）

**原理**：$U=E-Ir$；$U$-$I$ 图**纵截距 $=E$**、**斜率绝对值 $=r$**。

![](img/physics/emf-ur-image.svg)

### 两种接法的误差（高频考点）

**方案一（常用：电压表并电源、电流表串干路）**

电压表直接测路端电压 $U$（准确）；电流表测 $I=I_{\text{真}}-\dfrac{U}{R_V}$（**偏小**）。推导：真实 $U=E_{\text{真}}-r_{\text{真}}\,I_{\text{真}}$，代入 $I_{\text{真}}=I_{\text{测}}+\dfrac{U}{R_V}$ 得

$$U=\frac{E_{\text{真}}}{1+\frac{r}{R_V}}-\frac{r_{\text{真}}}{1+\frac{r}{R_V}}\,I_{\text{测}}$$

与 $U=E_{\text{测}}-r_{\text{测}}I$ 比较：**$E_{\text{测}}<E_{\text{真}}$、$r_{\text{测}}<r_{\text{真}}$**（图线整体"变平"）。

> 记法：**"电压表分流 → E、r 都偏小"**。

**方案二（电流表串干路、电压表接在电流表外侧，即电流表相对电源"内接"）**

$U_{\text{测}}=U_{\text{真}}+I R_A=E-I(r_{\text{真}}+R_A)$：**$E_{\text{测}}=E_{\text{真}}$（截距不变）**、$r_{\text{测}}=r_{\text{真}}+R_A$（**偏大**）。

> 结论对比：方案一 $E$、$r$ 都偏小；方案二 $E$ 准、$r$ 偏大。做选择题先判断"电压表有没有分走电流"。

### 变式：伏阻法 / 安阻法

- **伏阻法**（$R$-$V$ 并联）：$E=U+\dfrac{U}{R}r$ ⇒ $\dfrac1U=\dfrac1E+\dfrac rE\cdot\dfrac1R$；$\dfrac1U$-$\dfrac1R$ 图：纵截距 $\dfrac1E$、斜率 $\dfrac rE$；
- **安阻法**：$E=I(R+r)$ ⇒ $\dfrac1I=\dfrac1E R+\dfrac rE$；$\dfrac1I$-$R$ 图：斜率 $\dfrac1E$、纵截距 $\dfrac rE$。

## 例题

### 例 1（设计题·自编）

要测一个定值电阻 $R_x\approx8\,\Omega$，器材：电动势 $E=3\,\text{V}$ 电源（内阻不计）；电压表两块：$0\sim3\,\text{V}$（内阻 $3000\,\Omega$）、$0\sim15\,\text{V}$（内阻 $15000\,\Omega$）；电流表两块：$0\sim0.6\,\text{A}$（内阻 $0.5\,\Omega$）、$0\sim3\,\text{A}$（内阻 $0.1\,\Omega$）；滑动变阻器两只：$0\sim10\,\Omega$、$0\sim100\,\Omega$；开关导线若干。要求"电压从 $0$ 起调，测不少于 $5$ 组数据"。问：① 电表量程各选什么？② 电流表内接还是外接？③ 滑变用分压还是限流、选哪只？④ 计算结果与真实值的关系？

**解答**：

① 估算：分压时 $U_x$ 可达 $3\,\text{V}$（即电源电压，满量程但读数清晰），$I_{\max}\le\dfrac{3}{8}\approx0.375\,\text{A}$ → 选 $0\sim0.6\,\text{A}$、$0\sim3\,\text{V}$（若选 $3\,\text{A}$/$15\,\text{V}$ 则指针偏转太小，精度差）。

② $\sqrt{R_AR_V}=\sqrt{0.5\times3000}\approx38.7\,\Omega>R_x=8\,\Omega$ → 小电阻 → **外接**。

③ 要求"从 0 起调、多组数据"→ **分压**；分压式选**阻值较小的** $0\sim10\,\Omega$ 滑变（阻值太大调节曲线前段陡、后段平，且浪费功率）；注意额定电流需 $\ge\dfrac{E}{R_{\min}}=\dfrac{3}{10}\approx0.3\,\text{A}$。

④ 外接：${R_{\text{测}}}=\dfrac{U}{I_{\text{总}}}$，$I_{\text{总}}=I_{R}+I_{V}>I_R$ → $R_{\text{测}}<R_{\text{真}}$（"小外偏小"）。

### 例 2（误差方向·自编）

用"电压表并电源、电流表串干路"的电路测电动势 $E$ 和内阻 $r$，作 $U$-$I$ 图像得到截距 $E_0$、斜率 $-r_0$。下列说法正确的是（ ）

A. $E_0=E_{\text{真}}$，$r_0=r_{\text{真}}$　B. $E_0<E_{\text{真}}$，$r_0>r_{\text{真}}$

C. $E_0=E_{\text{真}}$，$r_0>r_{\text{真}}$　D. $E_0<E_{\text{真}}$，$r_0<r_{\text{真}}$

**解析**：电压表分流使电流表读数 $I_{\text{测}}<I_{\text{真}}$，把"真实的" $U=E_{\text{真}}-r_{\text{真}}I_{\text{真}}$ 换成 $I_{\text{测}}$ 表达（见上文推导）得测量图线截距与斜率都乘了 $1/(1+r/R_V)$ → 都比真实值小。**选 D**。

### 例 3（接法判定·自编）

研究小灯泡的伏安特性曲线，已知小灯泡额定电压 $3\,\text{V}$、额定电流 $0.3\,\text{A}$，正常发光时电阻约 $10\,\Omega$，灯丝冷态电阻约 $1\,\Omega$。器材：电源 $4.5\,\text{V}$、电压表 $0\sim3\,\text{V}$（内阻 $10\,\text{k}\Omega$）、电流表 $0\sim0.6\,\text{A}$（内阻 $0.2\,\Omega$）、滑变 $0\sim20\,\Omega$、开关导线。

① 滑变应用分压还是限流？② 电流表内接还是外接？③ 简述理由。

**解析**：

① **分压**。伏安特性曲线需要**电压从 0 起连续调**、测多组数据，且灯泡电阻随温度变化（非定值），限流式调不到 0、数据分布不合理；分压还能保证小电压下电流可测。

② **外接**。取 $R_x$ 的"工作值"判断：$R_x\approx10\,\Omega$，$\sqrt{R_AR_V}=\sqrt{0.2\times10^4}\approx44.7\,\Omega>10\,\Omega$ → 小电阻 → 外接。（灯丝冷态更小，仍属外接；如果按 $1\,\Omega$ 判断结论一样。）

③ 补充：分压电路中滑变 $20\,\Omega\gtrsim R_x$ 稍偏大，但题目给定量程内可用；若要求更精细可改小阻值滑变。

## 点评

- **判定分压还是限流，先找题干"从 0 开始 / 多组数据 / 伏安特性曲线"这类字眼**（出现必分压）；没有则按 $R_x$ 与滑变阻值关系选限流；
- 选电表先**估算再选**：量程宁大勿超、但别大到指针不动；两表量程最好同步（本例 $0.6\,\text{A}$ 与 $3\,\text{V}$ 对应）；
- 测 $E$-$r$ 的误差结论背死：**方案一（电压表并电源）$E$、$r$ 都偏小；方案二（电流表内接）$E$ 准、$r$ 偏大**；
- 画电路图时元件符号规范（滑变滑片箭头指向滑片、电表"+"接线柱），大题中"先大后小"的接法判断要写出比较式 $R_x^2$ 与 $R_AR_V$。
