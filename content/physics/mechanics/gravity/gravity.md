# 万有引力与天体运动

## 两大公式组（一切天体题的根）

1. **万有引力 = 向心力**（环绕天体）：$\dfrac{GMm}{r^2}=\dfrac{mv^2}{r}=m\omega^2r=m\dfrac{4\pi^2}{T^2}r$
2. **黄金代换**（星球表面）：$GM=gR^2$（把 $g$ 与 $M$ 互相翻译）

## 常用结论（推导三秒，套用三秒）

- 线速度：$v=\sqrt{\dfrac{GM}{r}}$；角速度：$\omega=\sqrt{\dfrac{GM}{r^3}}$；周期：$T=2\pi\sqrt{\dfrac{r^3}{GM}}$；
- **高轨低速大周期**：$r\uparrow$ → $v,\omega\downarrow$，$T\uparrow$；
- 密度：$\rho=\dfrac{3\pi}{GT^2}$（近地卫星周期求星球密度）。

## 三类常考卫星

| 卫星 | 特点 |
| --- | --- |
| 近地卫星 | $r=R$，$v=7.9\,\text{km/s}$（第一宇宙速度 = 最大环绕速度 = 最小发射速度） |
| 同步卫星 | 周期 $T=24\text{h}$，在赤道正上方，$h\approx3.6\times10^4\,\text{km}$，三定（周期/高度/轨道面） |
| 极地卫星 | 过南北极，用于全球观测 |

- 第二宇宙速度 $11.2\,\text{km/s}$（脱离地球），第三宇宙速度 $16.7\,\text{km/s}$（脱离太阳系）；
- 变轨：点火加速 → 轨道半径增大（离心），但**稳定后线速度反而变小**（高轨低速）。

## 双星模型（常见于选填）

- 两星绕**连线上一点**做圆周运动，角速度相同：$m_1r_1=m_2r_2$，$r_1+r_2=L$；
- 周期：$T=2\pi\sqrt{\dfrac{L^3}{G(m_1+m_2)}}$。

## 邪修提示

- 选填天体：**黄金代换 + 比例法**——两个卫星比较，把 $GM$ 当常数直接比 $\dfrac{1}{\sqrt r}$；
- "求星球密度/质量"：看见周期想 $\rho=\dfrac{3\pi}{GT^2}$；
- 同步卫星与赤道物体比较：赤道物体受支持力，**不能**用万有引力=向心力；
- 风险：$g$ 与 $r$ 的对应关系（表面用 $g$，高空用 $\dfrac{GM}{r^2}$），$r$ 必须是**到球心**的距离。
