# 受力分析

## 画力五步口诀

> **先重力，再接触（弹力→摩擦力），最后其他力（推力/电场/磁场）。**
>
> 口诀："**重力一定画，弹力看接触，摩擦看相对，其他逐条数**。"

1. **重力**：作用在重心，方向竖直向下（一切物体都要画）；
2. **弹力**：找接触面——有接触 + 有形变（或形变趋势）才有弹力，方向**垂直于接触面**（绳沿绳、杆可沿可不沿、指向恢复形变的方向）；
3. **摩擦力**：先判断接触面"粗糙 + 有相对运动（趋势）"；方向**沿接触面**，与相对运动（趋势）方向相反；静摩擦力大小看平衡/牛顿第二定律，滑动摩擦力 $f=\mu N$；
4. **其他力**：推力、拉力、电场力 $qE$、洛伦兹力 $qvB$（若涉及）逐条数，**别漏也不别多**；
5. **复查**：只画物体**受到的**力，不画它施给别人的力；每对"作用力反作用力"分别出现在谁的身上。

## 弹力判断的"移除法"

假想把支撑物抽掉：若物体运动状态会变化 → 有弹力；若无影响 → 无弹力。

## 摩擦力方向的"三步判断"

1. 确定**相对运动方向（趋势）**（假设接触面光滑，物体往哪动）；
2. 摩擦力**阻碍**它 → 方向与相对运动（趋势）相反；
3. 静摩擦力方向与**运动方向无关**（可以同向、反向、垂直——如传送带上的物体）。

## 整体法与隔离法（选讲，详见平衡专题）

- **整体法**：系统内部作用力不计，只画外力——系统加速度相同或均静止时优先；
- **隔离法**：对象内部就分析内力；
- 原则："**先整体求（系统外）未知，再隔离求（系统内）内力**"。

## 常见模型速记

| 模型 | 受力要点 |
| --- | --- |
| 斜面上物体 | 重力、支持力（垂直斜面）、摩擦力（沿斜面）；重力沿斜面分力 $G\sin\theta$ |
| 竖直墙+斜面夹球 | 重力、墙弹力（水平）、斜面支持力（垂直斜面） |
| 轻绳 | 拉力沿绳、同一根绳（光滑处）张力处处相等 |
| 轻杆 | 拉力/推力沿杆轴线 |
| 弹簧 | 弹力 $F=kx$，方向沿弹簧 |

## 易错点

1. 把"牛顿第三定律的相互作用力"误当平衡力（分别作用在两个物体上，谈不上平衡）；
2. 分析连接体时重复画绳子的力（内力不出现在整体法受力图里）；
3. 光滑接触面（无摩擦、无粗糙）也**有**弹力——"光滑"只说摩擦，不说弹力。

## 邪修提示

- 选填受力分析：**先整体**（忽略内力）再看局部，很多"求摩擦力"题一步出答案；
- 判断摩擦力方向：假设光滑看运动趋势，10 秒定位；
- 风险：一句话陷阱"物体静止在斜面上" ⟹ 摩擦力**沿斜面向上**（大小 $G\sin\theta$），与"沿斜面向下"猜反是经典失误。
