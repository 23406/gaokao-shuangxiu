# STSE 传统文化与化学工业速查

## 一、古籍中的化学（考法：古文→反应类型/方程式）

| 古籍典故 | 化学本质 | 反应/解释 |
|---|---|---|
| "曾青得铁则化为铜"（曾青 = 铜盐溶液，如胆矾） | 湿法炼铜（置换） | $\mathrm{Fe+CuSO_4=FeSO_4+Cu}$ |
| 《梦溪笔谈》"胆水浸铜" | 湿法冶金工业化（宋代） | 同上，铜的冶炼 |
| 火药"一硫二硝三木炭" | 黑火药（硝 = 硝酸钾） | $2\mathrm{KNO_3+S+3C}\xrightarrow{\text{点燃}}\mathrm{K_2S+N_2+3CO_2}$ |
| "石灰石煅烧"（《天工开物》石灰） | 碳酸钙高温分解 | $\mathrm{CaCO_3\xlongequal{高温}CaO+CO_2\uparrow}$ |
| 造纸（蔡伦） | 纤维素加工 | 草木灰+石灰水蒸煮：碱液脱木质素、漂白去杂 |
| 青铜铸器 | Cu-Sn 合金 | 合金硬度比纯铜**大**、熔点比纯铜**低** |
| 酿酒酿醋"以酒造醋" | 发酵 | 乙醇 $+O_2\xrightarrow{醋酸菌}$ 乙酸（先酒后醋） |

**记忆诀窍**：古代"炼铜炼铁"基本是**还原**（炭热还原 $\mathrm{Fe_2O_3+3CO\xlongequal{高温}2Fe+3CO_2}$）；"煮、蒸"多是**分离提纯**；"金属入溶液得紫红色物质"=**置换**。

## 二、近代化学工业（考法：流程 + 人物）

- **侯氏制碱法（联合制碱，1943 侯德榜）**：
  - 反应：$\mathrm{NH_3+CO_2+H_2O+NaCl=NaHCO_3\downarrow+NH_4Cl}$（NaHCO₃ 溶解度小析出）；
  - 顺序：**先通 NH₃ 后通 CO₂**——氨水碱性更强，吸收 CO₂ 更充分（先 CO₂ 后 NH₃ 吸收差、产率低）；
  - 优点：食盐利用率高、副产品 NH₄Cl 可作氮肥、无 CaCl₂ 废渣（对比索尔维法）。
- **合成氨**：$\mathrm{N_2+3H_2\xlongequal{催化剂,高温高压}2NH_3}$（哈伯·博施；工业条件 500℃ 左右、20~50 MPa。见 equilibrium-problem-template）。
- **青蒿素（屠呦呦，2015 诺贝尔生理学或医学奖）**：
  - 从青蒿中提取，**低温**、用**乙醚/醇**浸取——青蒿素**热不稳定**、受高温分解，传统"水煎"提不出有效成分；
  - 结构含**过氧键**（功效来源），分子式 $\mathrm{C_{15}H_{22}O_5}$。

## 三、性质 vs 用途（考法：配对找错）

| 物质 | 性质 | 用途 | 常见错误说法 |
|---|---|---|---|
| 明矾（$KAl(SO_4)_2\cdot12H_2O$） | 水解生成胶体**吸附** | 净水 | ❌"明矾能杀菌消毒"（只吸附沉降、无强氧化性） |
| NaOH | 碱性 | 制肥皂、除油污 | ❌"NaOH 中和胃酸"（腐蚀性，用 NaHCO₃ 或 Al(OH)₃） |
| NaHCO₃ | 受热/遇酸产生 CO₂ | 发酵粉、灭火器 | ✔ 胃酸过多（碱性弱、温和） |
| Fe₂O₃（铁红） | 红棕 | 红色涂料、炼铁原料 | 不是"磁性"材料（磁性用 Fe₃O₄） |
| SO₂ | 漂白（生成不稳定无色物） | 纸浆漂白 | ❌"SO₂ 能使红色变白 = 氧化漂白"（是**结合**漂白；品红褪色加热复红） |
| ClO₂ | 强氧化性 | 自来水消毒 | ✔ 消毒剂（取代液氯趋势） |
| 焰色反应 | 元素特征 | K 紫（透过蓝色钴玻璃） | "焰色"是**物理**变化（电子跃迁），不是化学变化 |

## 例题

### 例 1（选填）：古文辨识

**题目**（自编）《梦溪笔谈》记载"信州铅山县有苦泉，…，以水浸之，……其水可为铜"，即为胆铜法。下列说法错误的是：

A. 该过程利用了 Fe 的还原性

B. 发生反应 $\mathrm{Fe+CuSO_4=FeSO_4+Cu}$

C. 该法是"湿法炼铜"的雏形

D. 铜离子得电子被还原成铜单质，但铁在反应中作氧化剂

**标准解法**：

胆铜法反应：$Fe+CuSO_4=FeSO_4+Cu$。Fe 由 0 价升到 +2 价，**失电子、被氧化**（作还原剂）；$Cu^{2+}$ 由 +2 降到 0，**得电子、被还原**。A（Fe 具还原性）、B、C 均对；D 说"铁作氧化剂"——说反了，铁是**还原剂**，故选 D。

**点评**：① 古文题第一步是**把古文翻译成化学语言**：'苦泉'=硫酸铜溶液、'得铁则化为铜'=置换出铜；② 易错点：谁被氧化谁被还原——**失电子 = 被氧化 = 还原剂**，铁进溶液成浅绿色亚铁离子、铜析出成紫红色固体；③ 若问"现象"：铁表面出现红色固体，溶液由蓝色变浅绿色。

### 例 2（选填）：性质与用途

**题目**（自编）下列说法正确的是：

A. 明矾可利用其强氧化性对自来水杀菌消毒

B. 铁红（Fe₂O₃）可作红色涂料

C. SO₂ 漂白品红溶液，加热后不能恢复红色

D. 侯氏制碱法中应先通 CO₂ 后通 NH₃

**标准解法**：

明矾水解生成 Al(OH)₃ 胶体**吸附**杂质沉降，无强氧化性、**不能杀菌**，A 错。

铁红是红棕色粉末，作红色涂料，B 对。

SO₂ 漂白是**化合漂白**，生成无色不稳定物质，**加热可复红**（与 Cl₂ 氧化漂白不同），C 错。

先通 NH₃ 碱性更强、利于吸收 CO₂，再通 CO₂ 生成 NaHCO₃，D 错。

**点评**：①"净水"（明矾）与"杀菌消毒"（ClO₂、漂白粉、O₃）是两条线，考法爱混；② SO₂ 漂白"可逆"、Cl₂ 漂白"不可逆"、活性炭"物理吸附"，三种漂白机理必分清；③ 侯氏流程顺序"先氨后碳"是固定考法。

### 例 3（选填）：化学史与生活判断

**题目**（自编）下列有关说法错误的是：

A. 屠呦呦用乙醚低温萃取青蒿素，是因为青蒿素易受热分解

B. 青铜是铜锡合金，硬度比纯铜大

C. 侯德榜联合制碱法的副产品 NH₄Cl 可作氮肥

D. 黑色火药中硝酸钾作还原剂、硫作氧化剂

**标准解法**：

A 对：青蒿素热不稳定（这是乙醚低温萃取、不用水煎的原因）。

B 对：合金硬度大于成分金属（熔点通常低于成分金属）。

C 对：NH₄Cl 含氮、可作氮肥。

D 错：$\mathrm{2KNO_3+S+3C\rightarrow\cdots}$ 中 $\mathrm{KNO_3}$ 中 N 从 +5 降到 0（被还原）——**硝酸钾是氧化剂**；硫从 0 降到 K₂S 中的 -2（也被还原、作氧化剂）；碳升价被氧化、作还原剂。

**点评**：① 火药三成分的氧化还原角色：硝酸钾（氧化剂，氧源）、碳（还原剂）、硫（易点燃）；② "合金：硬度大、熔点低、耐腐蚀"三句话连在一起记；③ 化学史人物-成果配对：侯德榜-联合制碱、屠呦呦-青蒿素、门捷列夫-元素周期表、凯库勒-苯环结构、哈伯-合成氨。
