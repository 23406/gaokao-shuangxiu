# 离子反应与离子共存

## 离子方程式书写/判断六大陷阱

1. **拆分错误**：强酸强碱可溶性盐拆离子；弱酸（$CH_3COOH$、$HClO$）、弱碱（$NH_3\cdot H_2O$）、难溶物（$CaCO_3$、$BaSO_4$）、氧化物（$Na_2O$）不拆；
2. **守恒遗漏**：必须同时满足原子守恒 + 电荷守恒（$Fe^{2+}+Cl_2$ 配平常被考电荷）；
3. **量的关系**：少量/过量（$Ca(OH)_2$ 与 $NaHCO_3$：少量 $Ca(OH)_2$ 时 $OH^-$ 全用，$Ca^{2+}:OH^-=1:2$）；
4. **"微溶物"看状态**：$Ca(OH)_2$ 作反应物拆（澄清石灰水），作生成物不拆（悬浊液）；
5. **氧化还原**：$Fe^{2+}$ 与 $I^-$ 同时被氧化，写"谁先被氧化"；
6. **漏掉水电离**：$NH_4^+$ 与 $OH^-$ 反应不是简单的 $NH_4^++OH^-=NH_3\uparrow+H_2O$（浓溶液加热才逸出 $NH_3$）。

## 离子共存判断流程

1. **先看隐含条件**：
   - 无色溶液：排除 $Cu^{2+}$（蓝）、$Fe^{3+}$（黄）、$Fe^{2+}$（浅绿）、$MnO_4^-$（紫）；
   - 酸性条件：$pH<7$、$c(H^+)$ 大、与 Al 反应放 $H_2$（**可能酸可能碱**——两种情况分别检验）；
   - 碱性条件：$pH>7$、酚酞变红、水电离 $c(H^+)=10^{-13}$（酸或碱！）；
2. **再查五大不共存组**：
   - $H^+$ 与 $OH^-$、$CO_3^{2-}$、$HCO_3^-$、$S^{2-}$、$SO_3^{2-}$、$AlO_2^-$、$CH_3COO^-$；
   - $OH^-$ 与 $Mg^{2+}$、$Al^{3+}$、$Fe^{3+}$、$Cu^{2+}$、$NH_4^+$、$HCO_3^-$、$HS^-$；
   - 氧化还原：$Fe^{3+}$ 与 $I^-$、$S^{2-}$；$NO_3^-+H^+$（硝酸环境）氧化 $I^-$、$Fe^{2+}$、$S^{2-}$、$SO_3^{2-}$；
   - 双水解：$Al^{3+}$ 与 $AlO_2^-$、$HCO_3^-$、$CO_3^{2-}$、$S^{2-}$、$HS^-$；$NH_4^+$ 与 $AlO_2^-$；
   - 沉淀：$Ag^+$ 与 $Cl^-$、$Br^-$、$I^-$；$Ba^{2+}$ 与 $SO_4^{2-}$、$CO_3^{2-}$。

## 邪修提示

- 选填离子共存：**先找隐含条件，再逐个选项扫"经典毒药组合"**（$Al^{3+}+HCO_3^-$、$Fe^{3+}+I^-$、$NO_3^-+H^++Fe^{2+}$ 三连杀）；
- 离子方程式正误：**三查**——拆分查一遍、守恒查一遍、量比查一遍；
- 风险："与 Al 反应放 $H_2$"同时可能是强酸或强碱环境，漏讨论直接全错。
