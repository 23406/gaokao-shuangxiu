# 有机推断与合成

## 推断四步法

1. **算分子式**：由元素分析/质谱求最简式、分子式；
2. **算不饱和度**：$\Omega=\dfrac{2C+2-H}{2}$（含 $O$ 不影响，含 $N$ 时 $H$ 减 $N$）——判断是否有双键/环/苯环；
3. **特征反应定位官能团**（下表）；
4. **拼骨架**：由转化关系（连续氧化、酯化、消去加成）反推结构。

## 特征反应速查表（推断题全部题眼）

| 现象/反应 | 官能团 |
| --- | --- |
| 银镜 / 新制 $Cu(OH)_2$ 砖红 | 醛基 $-CHO$ |
| 与 $NaHCO_3$ 放出 $CO_2$ | 羧基 $-COOH$ |
| 与 $Na$ 放出 $H_2$ | 羟基/羧基 |
| $FeCl_3$ 显紫色 | 酚羟基 |
| 浓溴水白色沉淀 | 酚羟基（邻对位活化） |
| 溴水/高锰酸钾褪色 | $C=C$、$C\equiv C$ |
| 水解生成醇和酸 | 酯基 |
| 连续氧化 醇→醛→酸 | 伯醇（$\alpha$ 碳上有两个 H） |

## 常见转化链（必须背）

- 醇 $\xrightarrow{O_2}$ 醛 $\xrightarrow{O_2}$ 酸（碳原子数不变）——推断题最常用链条；
- 卤代烃 $\xrightarrow{NaOH水}$ 醇，$\xrightarrow{NaOH醇}$ 烯（消去）；
- 烯 $\xrightarrow{H_2O}$ 醇（加成），醇 $\xrightarrow{170°C}$ 烯（消去）；
- 酯化/水解互逆：酸+醇 $\rightleftharpoons$ 酯+水；
- 加聚与缩聚：含 $C=C$ 加聚（无小分子），含两个官能团（羟基+羧基等）缩聚（脱小分子）。

## 合成路线设计（新高考大题）

- 原则：**官能团引入 + 碳链增长/缩短 + 保护基**；
- 增长碳链：卤代烃与 $NaCN$、格氏试剂、醛的加成；
- 缩短碳链：烯烃臭氧氧化、羧酸盐脱羧；
- 官能团保护：酚羟基先酯化保护，防止被氧化；
- 答题模板："$A$ 在 $NaOH$ 水溶液中加热水解生成 $B$，$B$ 催化氧化生成 $C$…"——按转化链写箭头式。

## 同分异构体书写（常见漏写）

- 类别异构：醇↔醚、醛↔酮、羧酸↔酯、烯↔环烷；
- 限定条件（"能银镜+水解"）：先定官能团组合（甲酸酯 $-OOCH$），再排碳架；
- 核磁共振氢谱：峰数 = 等效氢种类数，面积比 = 氢原子数比。

## 邪修提示

- 选填/小推断：**特征反应表反查**，看到"银镜+水解"= 甲酸酯，秒杀；
- 不饱和度快速心算：$C_nH_m$ → $\Omega=\dfrac{2n+2-m}{2}$，一个苯环算 4；
- 分子式相差 $CH_2$ 是"同系物"信号，相差 $O$ 可能是"氧化"步骤；
- 风险：银镜反应要求碱性环境（氨银溶液）；"水解后能银镜"说明是**甲酸某酯**（$HCOOR$），不是普通酯。
