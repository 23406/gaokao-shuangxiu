## 题目

以乙烯为原料合成乙酸乙酯，合理的合成路线中中间体的正确顺序是（ ）

A. 乙醇 → 乙醛 → 乙酸 → 乙酸乙酯

B. 乙醛 → 乙醇 → 乙酸 → 乙酸乙酯

C. 乙酸 → 乙醛 → 乙醇 → 乙酸乙酯

D. 乙醇 → 乙酸 → 乙醛 → 乙酸乙酯

## 标准解法

**第一步：乙烯 → 乙醇**（加成）：$CH_2=CH_2+H_2O\xrightarrow{催化剂}CH_3CH_2OH$；

**第二步：乙醇 → 乙醛**（催化氧化）：$2CH_3CH_2OH+O_2\xrightarrow{Cu,\triangle}2CH_3CHO+2H_2O$；

**第三步：乙醛 → 乙酸**（氧化）：$2CH_3CHO+O_2\xrightarrow{催化剂}2CH_3COOH$；

**第四步：乙酸 + 乙醇 → 乙酸乙酯**（酯化）：$CH_3COOH+C_2H_5OH\xrightleftharpoons[浓H_2SO_4,\triangle]{}CH_3COOC_2H_5+H_2O$。

顺序：乙醇 → 乙醛 → 乙酸 → 乙酸乙酯，选 **A**。

## 邪修解法

**适用特征**：合成路线顺序 → **"连续氧化链"模板**：

> 醇 $\xrightarrow{O_2}$ 醛 $\xrightarrow{O_2}$ 酸 —— **碳原子数不变的 1:2:3 三兄弟**（丙醇→丙醛→丙酸同理）。

- 题目问"以乙烯合成乙酸乙酯" → 先加氢成**乙醇**，再两次氧化到**乙酸**，最后酯化；
- 锁定"乙醇→乙醛→乙酸"链，只有 A 正确。

**30 秒选 A**。

## 点评

- 酯化反应细节（最易错）：酸**脱羟基**、醇**脱氢**（同位素示踪 $^{18}O$ 记录在酯的氧上）；浓硫酸是催化剂+吸水剂；
- 逆推法：合成目标物 → 拆成"酸 + 醇" → 各自往上追原料（酯 → 酸+醇 → 醇可来自烯）；正推逆推双保险；
- 若题目给"以电石（CaC₂）为原料"，多一步：CaC₂ → 乙炔 → 乙烯（加氢）→ ...；
- 风险：乙醛氧化成乙酸用催化剂/银氨溶液都行；**苯甲醛**（无 α-H）**不能与新制 $Cu(OH)_2$（斐林试剂）反应**，但仍可被氧化成苯甲酸（酸性 $KMnO_4$、银氨溶液均可）——统一记忆："醛基一定能被氧化，但无 α-H 时斐林反应不灵"；而醇不一定能被氧化（叔醇不能）。
