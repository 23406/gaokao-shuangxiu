# 化学工艺流程题模板

> 工艺流程题 = 课本实验 + 工业思维，考的是"操作目的"和"原理分析"。设问高度套路化，模板背熟直接对号入座。

## 流程图的读法（三步）

1. **抓主线**：原料 → 预处理 → 核心反应 → 分离提纯 → 产品（箭头方向就是反应顺序）；
2. **找副线**：循环利用的物质（箭头指回前面的）、副产物（多用于"经济/环保"设问）；
3. **标状态**：固/液/气、温度、pH——每个条件都是设问点。

## 高频设问与标准答案模板

**"加快反应速率/提高浸取率"**：

> 增大接触面积（粉碎/搅拌）、适当升温、适当增大浓度（酸/碱）、延长浸取时间。

**"某操作的目的"**：

- 过滤：分离固液；蒸发浓缩冷却结晶：得到晶体（可溶性盐）；趁热过滤：防止晶体析出损失；
- 洗涤：除去表面杂质（"用…洗涤，目的是…"）；
- 调 pH：使某离子**完全沉淀**而其他离子不沉淀（"控制 pH 使 Fe³⁺ 转化为 Fe(OH)₃ 沉淀除去"）。

**"循环利用"**：降低成本、提高原料利用率、减少污染。

**"加过量 X 的目的"**：使反应物 Y 完全反应（提高 Y 的转化率）。

**"温度不宜过高"**：防止 X 分解/挥发/发生副反应（如 H₂O₂ 受热分解、NH₄HCO₃ 受热分解）。

## 常见"工业手段"背后的原理

| 手段 | 原理 |
| --- | --- |
| 粉碎/研磨 | 增大接触面积，加快反应速率，提高浸取率 |
| 酸浸/碱浸 | 使目标成分进入溶液（或使杂质溶解） |
| 氧化剂（H₂O₂/Cl₂） | 将低价离子氧化为高价（便于沉淀分离） |
| 萃取 | 溶质在两种溶剂中溶解度差异 |
| 电解精炼 | 阳极溶解阴极沉积，分离杂质 |

## 计算与 Ksp 结合（难点）

- "完全沉淀" = 离子浓度 $<10^{-5}\,\text{mol/L}$：由 $K_{sp}$ 反推所需 pH；
- 沉淀先后：$K_{sp}$ 小的先沉淀（同类型）；
- 答题模板："由 $K_{sp}(Fe(OH)_3)=…$ 得 $c(Fe^{3+})=10^{-5}$ 时 $c(OH^-)=…$，$pH=…$，故调 pH 至…"

## 邪修提示

- 设问"目的/作用/原因"：**从速率、转化率、分离、安全、环保五个角度凑**，写全不扣分；
- 流程题先看"循环箭头"——循环物质设问必有一问；
- 陌生方程式书写：根据流程中"反应物→产物"配平（电子守恒+电荷守恒）；
- 风险：答题必须"**结合本流程**"（写"使 Fe³⁺ 沉淀"而不是泛泛的"调节 pH"），空话不给分。
