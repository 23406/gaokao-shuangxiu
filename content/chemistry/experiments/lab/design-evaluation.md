# 实验方案设计与评价

> 化学实验大题的两大任务：**设计**（给你目标，让你写步骤）与**评价**（给你方案，让你判可否+说原因+给改进）。套路固定，术语精准就拿分。

## 三类方案的设计模板

### 1. 除杂/提纯类

**共同原则**：① 试剂只与杂质反应（不损耗主体）；② 不引入新杂质；③ 最终能分离（产物为纯净物）；④ 操作安全可行。

**顺序口诀**（液体除杂）：先除"干扰大的"，后补"可能引入的"。示例：$\mathrm{NaCl}$ 溶液中含少量 $\mathrm{Na_2CO_3}$，加适量盐酸即可（$\mathrm{CO_3^{2-}}$ 变 $\mathrm{CO_2}$，不引入新离子）；但 $\mathrm{Cl^-}$ 中混 $\mathrm{SO_4^{2-}}$ 应先加 $\mathrm{BaCl_2}$ 再加 $\mathrm{Na_2CO_3}$ 除多余 $\mathrm{Ba^{2+}}$，最后盐酸调中性——**每一步都要想"它给下一步埋了什么雷"**。

### 2. 检验类（证明某离子/气体存在）

**四步格式**：取少量样品 → 加特定试剂 → 观察并描述现象 → 下结论（"含……"）。

- **先排除干扰**：检验 $\mathrm{SO_4^{2-}}$ 先加**盐酸**再滴 $\mathrm{BaCl_2}$（排除 $\mathrm{CO_3^{2-}}$、$\mathrm{SO_3^{2-}}$ 的干扰，见"硫酸根检验"卡）；检验 $\mathrm{Cl^-}$ 用**稀硝酸**酸化（排除 $\mathrm{CO_3^{2-}}$ 沉淀）；
- 检验 $\mathrm{Fe^{2+}}$：先加 $\mathrm{KSCN}$ 无红色，再加氯水/$\mathrm{H_2O_2}$ 显红色（证明"没有铁离子+生成了铁离子"）；若直接加 $\mathrm{KSCN}$ 显红只能证明有 $\mathrm{Fe^{3+}}$；
- 气体检验：$\mathrm{CO_2}$ 用澄清石灰水变浑浊（题中说"使石灰水变浑浊"要警惕 $\mathrm{SO_2}$ 也能）；
- **只写"有白色沉淀"不行**，要写"**产生白色沉淀，且**继续加酸不溶解"这类完整现象。

### 3. 探究类（浓度/温度/催化剂的影响）

**固定结构**：提出假设 → 确定**单一变量** → 设计对照实验 → 预测现象 → 由现象得结论。

- **单一变量**：只改变要考察的那个因素，其他（温度、浓度、用量、容器）完全相同；
- 对照组：完整"空白对照"（不加催化剂/不放某物质）才说明问题；
- 结论句式："**在……条件下，……随……增大而……**"，别省略前提。

## 评价题的固定三问

| 问法 | 答题骨架 |
| --- | --- |
| 方案是否可行/合理？ | 可行/不可行 + **理由**（原理错 / 试剂不符合 / 引入干扰 / 现象不明显 / 操作危险 / 无法分离） |
| 为什么不选某方案？ | 针对题干更具体："若……则会产生/无法排除……干扰" + 比较优劣 |
| 如何改进？ | 换成某试剂 / 增加对照 / 先除干扰再检验 / 调整顺序（如"先沉淀后测定"） |

**措辞加分**：评价时用"**若……，则……**"的假设句式（如"若先加 $\mathrm{BaCl_2}$，则引入 $\mathrm{Cl^-}$，无法判断原溶液中是否含 $\mathrm{Cl^-}$"）——阅卷点就是对"引入干扰"的识别。

## 常见"无效方案"清单（选择题直接秒）

- 检验 $\mathrm{SO_4^{2-}}$ 用 $\mathrm{BaCl_2}$ **不加盐酸**（$\mathrm{CO_3^{2-}}$/$\mathrm{Ag^+}$ 干扰）；
- 检验 $\mathrm{Cl^-}$ 不加硝酸酸化；
- 蒸发结晶：蒸发至剩**少量水**（再冷却结晶），**不要蒸干**（固态产物易受热分解）；
- 滴定管未用待装液润洗；容量瓶未查漏；
- 除杂"过量"后不除去过量试剂本身；
- 收集气体/熄灭酒精灯的顺序颠倒（"先熄后防倒吸"，加热型制气）。

## 例题（自编）：SO₄²⁻ 与 Cl⁻ 共存时的检验顺序

某无色溶液可能含 $\mathrm{Na_2SO_4}$ 和 $\mathrm{NaCl}$。甲方案：先滴加 $\mathrm{BaCl_2}$ 溶液产生白色沉淀（证明含 $\mathrm{SO_4^{2-}}$），静置后取上层清液滴加 $\mathrm{AgNO_3}$ 产生白色沉淀（证明含 $\mathrm{Cl^-}$）。乙方案：先滴加 **稀硝酸**酸化，滴加 $\mathrm{Ba(NO_3)_2}$ 产生白色沉淀（沉淀不再溶解），再取上清液滴加 $\mathrm{AgNO_3}$ 产生白色沉淀。

**标准解法**：甲方案**错误**——加入的 $\mathrm{BaCl_2}$ 本身就引入了 $\mathrm{Cl^-}$，上层清液加 $\mathrm{AgNO_3}$ 的白色沉淀无法证明原溶液含 $\mathrm{Cl^-}$。乙方案正确：先除尽 $\mathrm{SO_4^{2-}}$（$\mathrm{Ba(NO_3)_2}$ 不引入氯），再检验 $\mathrm{Cl^-}$。

## 点评

- 检验类"设计"永远按**先验证/沉淀干扰离子 → 再检验目标离子**的顺序写；
- 高考评价题给的分几乎全在"干扰识别"上：谁引入了干扰？谁没除干净的干扰还在场？
- 试剂鉴别类（鉴别 $\mathrm{Na_2CO_3}$ 与 $\mathrm{NaHCO_3}$ 等）本质同检验：选一个**现象不同**的试剂，先想好"加什么、看到什么、各自什么结果"。
