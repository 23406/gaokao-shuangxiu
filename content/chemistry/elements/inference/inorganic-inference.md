# 无机推断·特征速查与四步脚本

## 突破口速查（框图中看见这些"字眼"直接锁定物质）

**颜色**：溶液——$\ce{Cu^{2+}}$ 蓝、$\ce{Fe^{3+}}$ 黄棕、$\ce{Fe^{2+}}$ 浅绿、$\ce{MnO4-}$ 紫红；沉淀——$\ce{Fe(OH)3}$ 红褐、$\ce{Cu(OH)2}$ 蓝、$\ce{Fe(OH)2}$ 白（空气中迅速变灰绿再变红褐，是它自身的"签名"）、$\ce{Al(OH)3}$/$\ce{Mg(OH)2}$/$\ce{CaCO3}$/$\ce{BaCO3}$ 白；单质——S 淡黄、$\ce{Br2}$ 红棕色液体、$\ce{I2}$ 紫黑、$\ce{Cl2}$ 黄绿、$\ce{NO2}$ 红棕。

**焰色**（物理变化）：$\ce{Na}$ 黄、$\ce{K}$ 紫（**透过蓝色钴玻璃**看）、$\ce{Ca}$ 砖红、$\ce{Ba}$ 黄绿、$\ce{Cu}$ 绿。

**特征气体**：$\ce{SO2}$（刺激性、品红褪色**加热复原**）、$\ce{Cl2}$（黄绿、品红褪色不复原——氧化漂白）、$\ce{NH3}$（使湿润红色石蕊变蓝 + 遇 $\ce{HCl}$ 白烟）、$\ce{NO}$（无色、遇空气变红棕）、$\ce{H2S}$（臭鸡蛋味）、$\ce{H2}$（爆鸣）、$\ce{CO2}$（使澄清石灰水变浑浊）。

**特征试剂**：能使润湿的淀粉-KI 试纸变蓝 = 氧化性气体（$\ce{Cl2}$、$\ce{NO2}$、$\ce{O3}$、$\ce{Br2}$ 蒸气）；使品红褪色 = $\ce{SO2}$ 或 $\ce{Cl2}$（复原可辨）；与 $\ce{Al}$ 反应放 $\ce{H2}$ 的溶液 = 强酸或强碱；先加 $\ce{KSCN}$ 无现象、再加氧化剂变红 = $\ce{Fe^{2+}}$；直接变红 = $\ce{Fe^{3+}}$；加 $\ce{K3[Fe(CN)6]}$（铁氰化钾）蓝色沉淀 = $\ce{Fe^{2+}}$。

## 特征转化链（"一步反应"关系是框图推断的骨架）

- **铝三角**（题眼最多）：金属铝 $\xleftrightarrow{\ \ce{H+}\ /\ \ce{OH-}\ }$ $\ce{Al^{3+}}$ $\xleftrightarrow{\ \ce{OH-}\text{(过量)/}\ \ce{H+}\text{(过量)}\ }$ $\ce{Al(OH)3}$ $\xleftrightarrow{\ \ce{OH-}\text{(过量)/}\ \ce{H+}\ }$ $\ce{[Al(OH)4]-}$（旧教材写作 $\ce{AlO2-}$，二者等价，按所用教材书写）。**关键差异**：$\ce{Al(OH)3}$ 溶于强碱**不溶于过量氨水**（氨水弱碱性，只能把 $\ce{Al^{3+}}$ 变沉淀：$\ce{Al^{3+}+3NH3.H2O = Al(OH)3 v + 3NH4+}$）；

![](img/chemistry/al-triangle.svg)
- **铁三角**：$\ce{Fe^{2+}}$ $\xleftrightarrow{\ \ce{Cl2}/\ \ce{HNO3}\ }\ \ce{Fe^{3+}}$，$\ce{2Fe^{3+}+Fe=3Fe^{2+}}$；向 $\ce{FeCl3}$ 中加铁粉颜色渐变；
- **钠链**：$\ce{Na -> Na2O -> Na2O2}$（或 $\ce{Na + H2O -> NaOH -> Na2CO3 -> NaHCO3}$）；$\ce{Na2O2}$ 与 $\ce{CO2}$/$\ce{H2O}$ 反应都放 $\ce{O2}$（生成 $1\,\mathrm{mol}\ \ce{O2}$ 转移 $2\,\mathrm{mol}\ \mathrm e^-$，O 从 $-1$ 价歧化）；
- **氯链**：$\ce{Cl2 + H2O <=> HCl + HClO}$；$\ce{Cl2}$ 制漂白粉 $\ce{2Cl2 + 2Ca(OH)2 = Ca(ClO)2 + CaCl2 + 2H2O}$；漂白粉失效 $\ce{Ca(ClO)2 + CO2 + H2O = CaCO3 v + 2HClO}$；
- **硫链**：$\ce{S -> SO2 -> SO3 -> H2SO4}$（第二步**催化剂、加热**）；$\ce{2H2S + SO2 = 3S v + 2H2O}$（归中）；
- **氮链**：$\ce{N2 ->[\text{工业合成}] NH3 ->[\text{催化氧化}] NO -> NO2 -> HNO3}$；雷雨中 $\ce{N2 + O2 -> NO}$（放电），$\ce{3NO2 + H2O = 2HNO3 + NO}$；
- **碳链**：$\ce{C -> CO -> CO2}$（$2\ce C+\ce O2=\ce{2CO}$ 是不完全燃烧；$\ce{CO}$ 还原性：$\ce{CO + CuO = Cu + CO2}$）。

## 推断四步脚本（读—标—推—验）

1. **读**：通读框图，圈出所有"反应条件"（点燃/催化剂/高温/电解/光照——条件本身就是线索，如"催化剂"往往指向 $\ce{SO2}$ 氧化、$\ce{NH3}$ 催化氧化、工业合成氨）与已知信息（颜色、焰色、特征气体）；
2. **标**：把能确定的物质名字直接写在框图上（哪怕只确定元素种类）；
3. **推**：从"最确定的物质"出发沿转化链推相邻物质，遇到分支看条件选路（如同一物质有两条路，用"反应条件 + 另一头已知物质"二选一）；
4. **验**：把推出的全部物质**按每一条反应核对一遍**（配平 + 条件 + 现象），全部吻合才算对——推断题"回代验证"是标准流程，不许跳步。

## 常见易错与坑

- $\ce{Al(OH)3}$ 能否溶于过量**氨水**：不能（与 $\ce{Zn(OH)2}$ 溶于氨水成配合物不同，别混）；
- 焰色反应是**物理变化**（元素性质），不是化学变化；
- $\ce{FeCl2}$ 溶液加氯水再加 $\ce{KSCN}$ 变红——**顺序**必须是先 $\ce{KSCN}$ 后氧化剂（先氧化再检验会把原有 $\ce{Fe^{3+}}$ 误判为 $\ce{Fe^{2+}}$ 氧化而来）；
- "白色沉淀"系列先问"是否溶于稀 $\ce{HNO3}$"：不溶 = $\ce{AgCl}$、$\ce{BaSO4}$；溶且放 $\ce{CO2}$ = 碳酸盐；
- $\ce{Na2O2}$ 与 $\ce{H2O}$/$\ce{CO2}$ 反应**不要写成生成 $\ce{O^{2-}}$**；氧化还原转移电子数按"歧化"算（1 mol $\ce{O2}$ 生成 ∝ 2 mol $\mathrm e^-$）。

## 邪修提示

- 框图题第一问通常是"写化学式/方程式"，先写会的那一问，**推断与书写互证**：写不出的方程式往往提示前面推错了；
- "无色气体 + 空气后变红棕" = $\ce{NO}$；"刺激性气体 + 品红褪色且加热复原" = $\ce{SO2}$；这两组是最高频送分突破口，看到直接圈出；
- $\ce{Al}$ 相关推断最常考的差别题："加入过量氨水还是过量 $\ce{NaOH}$"——先判沉淀是否溶解，再看溶解度；
- 风险：推断题的"突破口"必须依托题面证据，不允许"看着像就写"；大题中每写一个物质都要说明依据（什么特征现象/什么条件）。
