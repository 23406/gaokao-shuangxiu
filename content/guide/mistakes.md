# 跨科易错点总表

> 这是"总纲"页面：四科单科易错点见各科对应专题（如生物的 [生物概念辨析易错点](/node/biology/concept-pitfalls)），这里只收**跨科通用**的失分模式。考前把本页过一遍 ≈ 把最容易丢的 20 分捡回来。

## 一、审题关键词陷阱（全科通吃）

| 关键词 | 潜台词 | 典型坑 |
|---|---|---|
| 恰好 / 刚好 | 临界状态：速度减到 0、力恰好平衡 | 别把"恰好到达"当"到达"（可能只到一半） |
| 缓慢 / 缓慢地 | 全程近平衡，可逐状态列平衡式 | 误用牛顿第二定律 |
| 由静止 | 初速度 $v_0=0$ | 忘写初条件 |
| 足够长 / 一段时间后 | 常发展到一个稳定终态 | 分阶段讨论到稳定 |
| 标准状况 | 气体摩尔体积 $22.4\,\text{L/mol}$，**仅限气体** | 把液体/固体体积除以 22.4 |
| 常温常压 / 室温 | 催化剂活性、溶解度、淀粉酶失活温度等 | 拿"标准状况"条件套入 |
| 不计摩擦 / 光滑 / 忽略空气阻力 | 光滑斜面、理想滑轮 | 白写摩擦力做功 |
| 匀强 / 均匀 / 恒力 | 场、力恒定 | 非匀强场套 $E=U/d$ |
| 足够长时间 / 充分反应 | 反应进行完全；平衡 | 用瞬时值算 |
| 恰好开始 / 恰好停止 | 转动/滑动临界（静摩擦最大值） | $\mu$ 与动摩擦混用 |
| 最长 / 最短 / 最大 / 最小 | 极值问题 | 不检验端点、开闭区间 |

**审题三步**：① 圈出物理量单位；② 圈出"恰好/缓慢/足够"类修饰；③ 问句重读一遍（"下列说法**不正确**的是"是失分重灾区）。

## 二、计算与书写

1. **单位**：先统一到国际单位制再代数字（$\text{cm}\to\text{m}$，$g\to\text{kg}$，$\text{km/h}\div3.6\to\text{m/s}$）；结果带上单位（物理、化学都要）。
2. **有效数字**：结果保留位数与已知条件一致（一般 2~3 位）；化学计算题保留到与题给数据相同位数；**物理实验中"估读"**：刻度尺、电流表电压表读到最小刻度下一位。
3. **代数式 vs 数值**：大题第一问写代数式（先符号后数值），数值放最后；变量符号前后统一（$m$ 别一会儿质量一会儿米）。
4. **数量级检查**：算完用常识校对（人质量 $10^2\,\text{kg}$、家用电压 $220\,\text{V}$、常温 $300\,\text{K}$ 上下、原子半径 $10^{-10}\,\text{m}$）。结果离谱 → 回查公式或代错数。
5. **分类讨论**：分母含待定字母（$x=0$ 单独谈）、等比数列公比 $q=1$、空气阻力、轨道高度是否含地球半径……**讨论后检查是否漏"补集"**。

## 三、数学·高频失分

- **定义域先行**：对数真数 >0、偶次根号 ≥0、分母 ≠0、三角函数有界；反解后带回验证；
- **导数**：极值点 = 导数为 0 的**驻点**需检验（两侧变号才极值）；"在区间内单调"与"单调递增"的区分（是否允许常函数）；
- **立体几何**：建系后坐标写错是最大丢分点（原点、法向量方向符号）；
- **数列**：$a_n=S_n-S_{n-1}$ 只在 $n\ge2$ 成立——首项单独验证；
- **概率统计**："至少/至多"用对立事件；"不放回"与"放回"超几何 vs 二项分布别混；
- **圆锥曲线**：直线斜率不存在只斜截式漏掉；判别式与韦达要求"直线与曲线相交"前提。

## 四、物理·高频失分

- **矢量**：答"大小+方向"，正负号表示方向（速度、加速度、电场力）；
- **功/能量**：摩擦力做负功、重力做功与路径无关（只与高度差有关）、势能零面自选但同一题统一；
- **电学**：$\dfrac{Q}{C}$ 与 $CU$ 混淆；$E=IR+Ir$ 中 I 是同一支路电流（内阻分流陷阱）；伏安法误差口诀（见 [电学实验设计](/node/physics/experiments/electricity-lab/experiment-design)）；
- **力学**：绳轮连接体"加速度沿绳分量相等"；**圆周运动最高点临界**（绳 $v\ge\sqrt{gR}$、杆 $v\ge0$）；
- **图像**：$x$-$t$ 图斜率是速度，$v$-$t$ 图斜率是加速度、面积是位移（$a$-$t$ 图面积是 $\Delta v$！）。

## 五、化学·高频失分

- **量的概念**：质量分数、物质的量浓度、系数比（物质的量）别混；$c_{\text{稀}}\cdot V_{\text{稀}}=c_{\text{浓}}\cdot V_{\text{浓}}$ 仅稀释；
- **离子共存**："无色""酸性（pH<7）/碱性""与 Al 反应产生 H₂""能水解"各是不同限制条件；
- **反应次序**：向含 $\text{NaOH}$、$\text{Na}_2\text{CO}_3$ 溶液滴稀盐酸——先中和 $\text{OH}^-$、再 $\text{CO}_3^{2-}\to\text{HCO}_3^-\to\text{H}_2\text{CO}_3$（分段不共存）；向含 $\text{Na}_2\text{SO}_3$、$\text{NaI}$ 的溶液通 $\text{Cl}_2$——**还原性强者先被氧化**：$\text{SO}_3^{2-}$ 的还原性强于 $\text{I}^-$（对应电极电势更低），先被氧化；
- **离子方程式**：**量不同方程式不同**（过量/少量、比值）；△、↑、↓、催化剂、条件全写；
- **计算守恒**：先写关系式法（得失电子守恒 / 元素守恒 / 电荷守恒）再代数据；
- **Ksp**：比较沉淀先后要**同型**（同为 AB 或 A₂B），否则算离子浓度。

## 六、生物·高频失分

- **系谱图**：先数"无中生有"定隐性、"有中生无"定显性；世代数、性别、个体编号别漏；
- **遗传计算**："子代中表现型 XX 的概率" vs "表现型为 XX 的后代中某基因型的概率"——分母不同；
- **减数分裂**：一个精原细胞 vs 一个个体产配子类型数（前者最多 2 种，后者 $2^n$）；
- **实验设计**：自变量/因变量/对照/重复每组都写；**无关变量相同且适宜**这句必写；
- **长句表述**：句式"（结构/部位）＋（体现的生理过程）＋（结果/意义）"，如"下丘脑合成、垂体释放的抗利尿激素促进肾小管、集合管对水的重吸收"；
- **教材黑体字结论**：蛋白与核酸的关系、光合与呼吸过程、生态系统能量流动单向逐级递减（10%~20%）。

## 七、最后 5 分钟检查清单

1. 填空题单位、符号是否与题干一致；
2. 计算式子代入数字后有没有把 $\times10^{-3}$ 之类漏掉；
3. "正确的是/不正确的是"看清方向；
4. 作图题：坐标轴名称 + 单位 + 描点线型（直线还是曲线）；
5. 先写第一问的**结论句**（"由 $XXX$ 可知……"），阅卷老师找答案更快。
