# 内容规范（Content Schema）

所有内容都是 **Markdown 文件**，放在 `content/` 下。目录结构 = 知识树结构，改动即上线。

## 目录与文件命名

- 每层分类 = 一个目录，目录内放 `_index.md` 写分类说明（frontmatter 里 `title` 必填，`desc` 选填）。
- 每个内容条目 = 一个 `.md` 文件，文件名用英文小写 + 连字符（slug），如 `induction-formulas.md`。
- 分类层级示例：

```
content/math/functions/trigonometry/
├─ _index.md          # 分类页：三角函数
├─ induction-formulas.md   # 知识点
├─ trig-mnemonics.md      # 口诀卡
└─ examples/
   ├─ induction-special-value.md  # 例题（带邪修）
   └─ induction-simplify.md       # 例题（无邪修）
```

## Frontmatter 字段

```yaml
---
title: 诱导公式            # 必填：显示标题
type: knowledge           # 必填：knowledge 知识点 | example 例题 | mnemonic 口诀卡
status: draft             # draft 草稿（默认）| reviewed 已复核
keywords: [诱导公式, 口诀]  # 选填：搜索关键词
summary: 一句话摘要         # 选填：默认自动截取正文
source: 2024新课标Ⅰ卷·第7题  # 例题专用：来源（真题写 年份+卷别+题号；自编写"自编"）
difficulty: 中档           # 例题专用：基础/中档/较难
applicability: 选填专用     # 例题专用（有邪修时必填）：适用范围
risk: 特殊值法仅限选填…      # 例题专用（有邪修时必填）：风险提示
fit:                       # 例题专用（有邪修时必填）：适用特征列表
  - 求值题，条件只有一个等式
  - 选填题，不需要过程
updated: 2025-02-01       # 选填：最后更新日期
---
```

> ⚠ **YAML 引号坑**：`risk`/`summary`/`title` 等字段的值如果**以 ASCII 双引号开头**（如 `risk: "xxx"要求…`）会解析失败。要么用全角引号（`“ ”`），要么把整个值用引号包起来。`npm run content` 报 YAML 错误时会指出具体文件。

## 例题的正文结构（必须用二级标题分节）

```markdown
## 题目
（题目原文）

## 标准解法
（完整步骤，可含 LaTeX 公式）

## 邪修解法
（速解思路。**没有就整段不写**，页面会自动只显示标准解法）

## 点评（选填）
```

构建管线会把 `标准解法` 和 `邪修解法` 拆成左右并排两栏；有 `## 邪修解法` 但缺 `risk/applicability/fit` 会报警告。

## 公式与化学式

- 数学公式用 LaTeX：行内 `$x^2$`，独立公式 `$$...$$`。
- 化学式用 KaTeX 的 mhchem：`\ce{H2O}`、`\ce{Fe^{3+} + e- -> Fe^{2+}}`。
- 不支持的复杂结构式（苯环等）暂时用文字描述，后续配 SVG 图。

## 配图规范（图文结合）

1. **示意图**（受力图/电路图/几何图）优先**自绘 SVG**，放 `public/img/`，Markdown 里引用相对路径：`![](img/physics/incline-force.svg)`；
2. **外部图片**只允许**明确自由许可**的图源（Wikimedia Commons 等），必须标注作者与许可（在内容末尾加"图片来源"附注）；**禁止**搬运有版权的水印图/教辅截图；
3. 自绘 SVG 规范：`viewBox` + 显式 `width/height`；用 `<defs><marker>` 画箭头；配色 G 黑 / N 蓝 / f 红 / 外力橙绿，圆角小字说明；**曲线用程序采样生成**（三角函数/logistic），不要手绘贝塞尔路径——手绘容易画错方向/被裁剪；
4. **发布前必须在网页里截图验收**：build + preview 后打开对应页面，截 `<img>` 元素，人工检查方向、裁剪、交点、标签——本项目已因截图验收发现并修复过 4 张图的问题（波动图裁剪、S 型曲线的 K/2 错位、CO₂ 曲线"回升"方向反、滴定曲线方向反）。

## 提交检查清单

1. `npm run content` 无警告输出（有警告会打印 `[warn]` 行）。
2. 例题有邪修时三件套齐全：`applicability` + `risk` + `fit`。
3. **邪修宁缺毋滥**：没有靠谱/独到的巧解就**只写标准解法**（页面自动只显示标准栏），不要为凑"双解"硬编造邪修；有邪修必须注明边界：只在什么题型下成立。
4. 真题引用注明卷别题号；自编内容标注"自编"。
5. **二级结论必须附推导**：知识卡/例题里出现的"结论/公式/秒杀口诀"，正文**至少写 2~3 行关键推导**（来源原理→代数变形）；选填可以直接用结论，**大题必须按推导步骤书写**，纯抄结论按"无依据"扣分。凡结论前必须说明"选填可用/大题需推导"。
