# 神经调节

## 反射与反射弧

- 神经调节的基本方式：**反射**（在中枢神经系统参与下，对内外刺激作出的规律性应答）；
- 反射弧五部分：感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器；
- 判断技巧：**有神经节的是传入神经；切断实验**：切断后刺激近中枢端无反应 → 切断的是**传出**神经（刺激外周端无反应 → 切断的是**传入**神经）。

## 兴奋在神经纤维上的传导（电信号/局部电流）

- 静息电位：**外正内负**（$K^+$ 外流，$K^+$ 通道开放）；
- 动作电位：**外负内正**（$Na^+$ 内流，$Na^+$ 通道开放）；
- 兴奋以**电信号**（局部电流）形式双向传导（在离体纤维上）；
- 电流方向：膜外由未兴奋→兴奋（正→负），膜内由兴奋→未兴奋；
- 电位变化曲线：静息（-70mV）→ 去极化（Na⁺内流，+35mV）→ 复极化（K⁺外流）→ 恢复。

## 兴奋在神经元之间的传递（突触）

- 突触结构：突触前膜 + 突触间隙 + 突触后膜；
- 传递过程：突触小泡（神经递质）→ 突触前膜 → 突触间隙（扩散）→ 突触后膜（受体）→ 下一个神经元兴奋或抑制；
- 特点：**单向传递**（只能从突触前膜到突触后膜），比神经纤维传导**慢**；
- 神经递质：乙酰胆碱（兴奋性）、多巴胺、甘氨酸（抑制性）；作用后被降解或回收（否则持续兴奋）。

## 分级调节与高级中枢

- 大脑皮层：最高级中枢（语言、感觉、运动）；脊髓：低级中枢（膝跳反射）；
- 高级中枢对低级中枢有**调控**作用（如憋尿：高级中枢控制低级中枢）。

## 邪修提示

- 电位图题：**"外正内负是静息，外负内正是兴奋"**，看到图先标内外电荷；
- $Na^+$/$K^+$ 通道阻断剂：阻断 $Na^+$ 内流 → 不能产生动作电位；阻断 $K^+$ 外流 → 静息电位异常；
- 电流表偏转判断：刺激后两个电极先后兴奋 → 偏转 2 次方向相反；同时兴奋 → 不偏转（膜内外电流抵消——其实同侧同时兴奋不偏转）；
- 突触传递方向判断：看图找"突触小泡"在哪一侧（突触前膜侧）；
- 风险：兴奋在**神经纤维上**双向、在**突触间**单向——"在反射弧中只能单向"是因为突触。
