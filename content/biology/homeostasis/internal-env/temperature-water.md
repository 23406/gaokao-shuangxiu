# 体温调节与水盐平衡

## 体温调节：产热与散热两条账

**产热**：细胞代谢产生；安静时以**肝脏**为主，运动时（寒冷时战栗）以**骨骼肌**为主；寒冷时骨骼肌"战栗"是增产热的重要方式。

**散热**：**皮肤是人体最主要的散热器官**——常温下靠辐射、对流、传导；环境温度接近/超过体温时，**汗液蒸发成为主要散热途径**；呼吸也带走少量热量。

**寒冷时的人体应答**（神经-体液调节）：

1. 皮肤冷觉感受器 → 传入**下丘脑体温调节中枢**；
2. 神经调：皮肤血管**收缩**（减少散热）、骨骼肌**战栗**（增加产热）、汗腺分泌减少；
3. 体液调：**甲状腺激素、肾上腺素**分泌增多 → 代谢增强、产热增多。

**炎热时**相反：皮肤血管舒张、汗液分泌增多（散热增多）。

**动态平衡**：体温恒定 ⇔ 产热 = 散热（动态平衡）。发烧"上升期"产热 **>** 散热，维持期产热 ≈ 散热（高位），退烧期产热 **<** 散热——三个时期要分清。

## 水盐平衡：渗透压感受器 + 抗利尿激素

**水的来去**：来源 = 饮水、食物、代谢产生的水；去向 = **肾（主要）**、皮肤（汗）、肺呼出、大肠（粪便）。

**失水/吃咸（细胞外液渗透压升高）** → 下丘脑的**渗透压感受器**兴奋 → 两条路：

1. **渴觉**：兴奋传至**大脑皮层**产生渴觉（在大脑皮层，不是下丘脑！）→ 主动饮水；
2. **抗利尿激素（ADH）**：由**下丘脑**分泌、**垂体**释放，量增多 → 促进**肾小管和集合管**对水的重吸收 → 尿量减少。

**多饮水**：渗透压降低 → ADH 分泌减少 → 肾小管集合管重吸收水减少 → 尿量增多。

**Na⁺ 平衡**：由肾上腺**皮质**分泌的**醛固酮**促进肾小管、集合管对 Na⁺ 的重吸收、对 K⁺ 的排出（"保钠排钾"）。

**调节方式定性**：神经-体液调节（下丘脑是"神经中枢 + 分泌细胞"的双重角色）。

## 长句答题模板（生物非选必背"三段讲全"结构）

> 环境温度降低时，皮肤冷觉感受器兴奋，传入下丘脑的体温调节中枢；通过传出神经使皮肤血管收缩、汗腺分泌减少、骨骼肌战栗；同时下丘脑—垂体—甲状腺轴活动加强，甲状腺激素分泌增多，使细胞代谢加快、产热增多，从而维持体温相对稳定。

> 饮水过少或食物过咸时，细胞外液渗透压升高，刺激下丘脑渗透压感受器；一方面兴奋传至大脑皮层产生渴觉，促使主动饮水；另一方面下丘脑分泌、垂体释放的抗利尿激素增多，促进肾小管、集合管对水的重吸收，使尿量减少，渗透压恢复平衡。

得分点检查：**说了谁高兴+谁分泌什么+干了什么事+恢复什么**（每一步都要有"结果句"）。

## 邪修提示

- 口诀"冷缩热张"：寒冷→血管收缩、汗少；炎热→血管舒张、汗多；
- ADH 三个位置别串："下丘脑**合成**、垂体**释放**、肾小管集合管**干活**"——选填最爱拿这三个位置互相换；
- "渴觉"永远选**大脑皮层**；"渗透压感受器"永远选**下丘脑**；
- 判断调节方式：有"神经中枢→传出神经"结构 = 神经调节；答案里出现"激素经体液运输"才能答"体液调节"；两者都出现答"神经-体液调节"；
- 风险：长句题只写"体温下降"不写"产热/散热具体路径"会拿不到关键分；发热≠环境温度高，別答"环境高温"作为发烧理由。
