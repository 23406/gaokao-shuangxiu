# 细胞的生命历程

## 有丝分裂（口诀："膜仁消失现两体"）

| 时期 | 特征 |
| --- | --- |
| 分裂间期 | DNA 复制（$2n\to4n$）、蛋白质合成——**占时间最长** |
| 前期 | 膜仁消失现两体（染色体、纺锤体出现） |
| 中期 | 染色体着丝点排列在赤道板上，**数目最清晰**（观察最佳时期） |
| 后期 | 着丝点分裂，姐妹染色单体分开，染色体数**加倍** |
| 末期 | 膜仁重现失两体（核膜核仁重建，纺锤体消失） |

- 染色单体数 = 0 的时期：间期复制前、后期、末期；
- 动物/植物区别：**高等**植物无中心体（细胞板→细胞壁），动物和低等植物有中心体（缢裂）。

## 细胞分化

- 实质：**基因的选择性表达**（细胞中 mRNA/蛋白质不同，DNA 相同）；
- 特点：持久性、稳定性、不可逆性；
- 全能性：已分化的细胞仍具有发育成完整个体的潜能——**动物体细胞的细胞核**具有全能性（克隆羊原理；大小排序见下行）；
- 全能性大小：受精卵 > 干细胞 > 体细胞；植物细胞 > 动物细胞。

## 衰老与凋亡

- 衰老细胞特征：水分减少（体积变小）、酶活性降低、色素积累、细胞核增大、细胞膜通透性改变；
- 细胞凋亡：**基因控制的程序性死亡**（对生物体有利）：细胞编程性死亡、蝌蚪尾巴消失、被病原体感染细胞的清除；
- 细胞坏死：外界不利因素引起的**被动**死亡（不利）。

## 癌细胞

- 特征：无限增殖、形态结构改变、细胞膜上糖蛋白减少（**易分散转移**）；
- 成因：原癌基因（调节细胞周期）和抑癌基因突变；
- 预防：远离致癌因子（物理/化学/病毒）。

## 邪修提示

- 图像题数染色体：**数着丝点**（有几个着丝点几条染色体），别数染色单体；
- "分化后 DNA 相同、RNA 不同"是判断选择题的万能钥匙；
- 凋亡 vs 坏死："主动/程序性/有利"→凋亡；"被动/损伤"→坏死；
- 风险：有丝分裂后期染色体数加倍但 DNA 数不变；观察根尖分生区细胞分裂的装片时，**间期细胞最多**。
