# 减数分裂与受精作用

## 核心过程（染色体数变化：$2n\to n\to n$）

| 阶段 | 关键事件 |
| --- | --- |
| 间期 | DNA 复制（染色体数不变，DNA 加倍） |
| 减Ⅰ前期 | 同源染色体联会，形成**四分体**，可发生**交叉互换** |
| 减Ⅰ后期 | **同源染色体分离**（等位基因分离），非同源染色体自由组合 |
| 减Ⅱ后期 | 着丝点分裂，姐妹染色单体分离（等位基因也可在此分离——交叉互换后） |

- 减Ⅰ分裂：同源染色体分离，染色体数减半；
- 减Ⅱ分裂：着丝点分裂，类似于有丝分裂（无同源染色体）。

## 图像识别三步法（必考）

1. **看有无同源染色体**：无 → 减Ⅱ（有丝分裂后期**有**同源染色体，不会落入此分支，别混淆）；有 → 下一步；
2. **看是否联会/同源分离**：是 → 减Ⅰ；否 → 有丝分裂；
3. **看是否均等分裂**：不均等 → 卵细胞形成过程。

**口诀**："有同源联会分离是减一，无同源是减二，其他看图像"。

## 精卵形成对比

| 比较 | 精子 | 卵细胞 |
| --- | --- | --- |
| 分裂方式 | 均等分裂 | 不均等分裂（产生极体） |
| 结果 | 1 个精原细胞 → 4 个精子 | 1 个卵原细胞 → 1 个卵细胞 + 3 个极体 |

## 减数分裂与有丝分裂图像辨析（选填图）

- 中期：有丝分裂（同源染色体排列赤道板两侧？不——有丝分裂中期同源染色体**不配对**，各自排列）；减Ⅰ中期四分体排列赤道板；减Ⅱ中期无同源；
- 后期：有丝分裂后期有同源且着丝点分裂；减Ⅰ后期同源分离；减Ⅱ后期无同源。

## 受精作用

- 精子卵细胞融合，染色体数恢复 $2n$；
- 意义：维持前后代染色体数目恒定；使后代具有两个亲本的遗传物质（多样性来源之一：自由组合 + 交叉互换 + 受精随机）。

## 邪修提示

- 染色体/DNA 数变化图：**看"减半"发生在哪**——染色体减半在减Ⅰ末期（同源分离），DNA 减半也是减Ⅰ（细胞分裂）；减Ⅱ后期染色体数暂时加倍；
- 四分体数 = 同源染色体对数；"四分体时期"就是减Ⅰ前期；
- 交叉互换只发生在**同源染色体的非姐妹染色单体**之间（选填最爱挖坑：姐妹染色单体间互换无意义）；
- 风险：减Ⅱ后期着丝点分裂后染色体数与体细胞相同（$2n$），别误判为有丝分裂后期（后者有同源染色体）。
