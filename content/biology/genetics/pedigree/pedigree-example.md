## 题目

某家族系谱图中，Ⅰ₁ 和 Ⅰ₂（均正常）生了一个患病的儿子 Ⅱ₁；Ⅱ₁ 与正常女性 Ⅱ₂ 结婚，生了一个正常女儿 Ⅲ₁。则该病（ ）

A. 一定是常染色体隐性遗传

B. 一定不是伴 X 染色体显性遗传

C. 若为常染色体隐性遗传，Ⅲ₁ 携带致病基因的概率为 $\dfrac23$

D. 该病为伴 X 染色体隐性遗传的概率最大

![](img/biology/pedigree.svg)

## 标准解法

**第一步（显隐性）**：Ⅰ₁×Ⅰ₂ 正常，生出患病儿子 Ⅱ₁ → "**无中生有**" → 隐性遗传病。

**第二步（定位染色体）**：隐性遗传可能是常染色体隐性或伴 X 隐性：

- 若为伴 X 隐性：Ⅱ₁（$X^aY$）与正常女性 Ⅱ₂（$X^AX^A$ 或 $X^AX^a$）……题目只告诉我们 Ⅲ₁ 正常，信息不足，不能确定是哪种——但题目问的是判断选项。

**第三步（逐项判断）**：

- A：只说"一定"——信息不足，✘；
- B：该病是隐性，伴 X 显性不可能（显性病"有中生无"才对）✓；
- C：若常隐，Ⅱ₁ 为 $aa$，Ⅱ₂ 正常（$AA$ 或 $Aa$），Ⅲ₁ 正常——Ⅱ₁ 只提供 $a$ 配子，Ⅲ₁ 正常必从父得 $a$、从母得 $A$，故 Ⅲ₁ **必为 $Aa$（携带者概率 $=1$）**；C 的 $\dfrac23$ 是"双亲均携带者、已排除 $aa$"场景的数据，此处不适用，✘；
- D："概率最大"没有依据，✘。

选 **B**。

## 邪修解法

**适用特征**：系谱图 → 两句口诀 + "最可能"思维：

> **无中生有为隐性，有中生无为显性**（父母正常生患病 → 隐性；父母患病生正常 → 显性）；
> 隐性遗传看女病（女病父子病 → 伴 X 隐），显性遗传看男病（男病母女病 → 伴 X 显）。

**扫题（30 秒）**：

1. Ⅰ₁、Ⅰ₂ 正常，儿子患病 → 隐性 ✓；
2. 是隐性 → 绝不可能是伴 X **显性**（显性病的特征是"有中生无"）→ **B 必对**；
3. A 说"一定是常隐"→ 信息不足不能"一定"；C 的 $\dfrac23$ 是"双亲均携带者、已排除 $aa$"场景的数据，而本题 Ⅲ₁ 携带概率实际为 $1$（Ⅱ₁ 只给 $a$，Ⅲ₁ 正常必从母得 $A$）→ C 错；D"概率最大"无从谈起。

选 **B**。

## 点评

- 口诀本质：显性病"有中生无"（患者双亲必有患者），隐性病"无中生有"；
- $\dfrac23$ 的适用场景（常考模板）：已知**双亲都是携带者**（$Aa\times Aa$），生一个正常孩子，该孩子为携带者的概率是 $\dfrac23$——注意前提是"已排除 $aa$"；
- 系谱题陷阱："信息不足"时只能选"最可能/一定不是"型选项；
- 大题书写模板：先写"无中生有为隐性"→ 再写"若为伴 X 隐性则……若为常隐则……"分情况讨论。
