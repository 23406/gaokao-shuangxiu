# 遗传规律

## 两大定律（孟德尔）

1. **分离定律**：等位基因随同源染色体分开而分离（$Aa\to A:a=1:1$）；
2. **自由组合定律**：非同源染色体上的非等位基因自由组合（$AaBb$ 产生 4 种配子 1:1:1:1）。

## 9331 与变式（选填杀手锏）

$AaBb\times AaBb$ 标准：**9:3:3:1**，变式全表：

| 比例 | 含义 |
| --- | --- |
| 9:7 | 双显性 A_B_ 一种性状，其余一种（互补） |
| 9:3:4 | 双显一种，单显（A_bb）一种，其余（aaB_+aabb）一种 |
| 9:6:1 | 双显一种，单显两种合并，双隐一种（累加） |
| 15:1 | 只要有显性基因就是同一性状 |
| 12:3:1 | 显性上位 |
| 13:3 | 抑制基因 |

**拆分法**（邪修核心）：9:3:3:1 = (3:1)×(3:1)，任何变式都能拆成两对基因独立遗传——看到"16 份"就是两对基因。

## 伴性遗传

- **伴 X 隐性**（红绿色盲、血友病）：男患者多；女患者的父亲和儿子必患病；"交叉遗传"（外公→女儿→外孙）；
- **伴 X 显性**（抗 VD 佝偻病）：女患者多；男患者的母亲和女儿必患病；
- **伴 Y**：只传男（外耳道多毛症）。

## 系谱图判断口诀

> **无中生有为隐性**（父母正常生患病孩子 → 隐性）；
> **有中生无为显性**（父母患病生正常孩子 → 显性）；
> 隐性遗传看女病：女病父子病 → 伴 X 隐性；
> 显性遗传看男病：男病母女病 → 伴 X 显性。

## 概率计算模板

- 分离比法：$Aa\times Aa$ → $AA:Aa:aa=1:2:1$，患病概率 1/4（隐性）；
- 自由组合拆分：$AaBb\times AaBb$ → 先拆两对分别算再相乘；
- "患病男孩" vs "男孩患病"：前者 ×1/2，后者不乘（性别已知）。

## 邪修提示

- 比例题：**数总份数**——16 份两对基因，4 份一对基因（性状分离 3:1 或 1:2:1）；
- 9331 变式：先写标准 9:3:3:1，再按题目合并（9:3:4 = 3+1 合并）——别重推；
- 系谱图：口诀两句话定位显隐性，再套"看女病/男病"定位染色体；
- 风险："自由组合"必须有"非同源染色体"前提（一对染色体上的两对基因连锁，不自由组合）。
