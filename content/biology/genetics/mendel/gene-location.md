## 题目

已知某昆虫的一对相对性状由一对等位基因控制，现有纯合突变型与纯合野生型个体（雌雄均有）。为判断该基因位于常染色体还是 X 染色体上，最合适的实验方案是（ ）

A. 用突变型雄性与突变型雌性杂交

B. 分别进行正反交（♂突变×♀野生 与 ♂野生×♀突变），比较子代表现型

C. 用野生型雌雄个体杂交

D. 任意正交一次即可判断

## 标准解法

**正反交判断法**：

- 若基因位于**常染色体**：正反交基因型组合相同（$AA\times aa$ 与 $aa\times AA$ 等价），后代表现型及比例**一致**；
- 若基因位于**X 染色体**：正反交组合不同（$X^AX^A\times X^aY$ 与 $X^aX^a\times X^AY$），后代表现型**不一致**（交叉遗传：雌雄表现差异）。

所以做**正反交**并比较子代：结果相同 → 常染色体；结果不同 → 伴 X（再结合交叉遗传特征确认）。选 **B**。

## 邪修解法

**适用特征**：判断常染色体 vs 伴 X → **口诀**：

> **"判断伴性，正反交见分晓"**：正反交结果相同 → 常染色体；不同 → X 染色体。

- A、C：同一性别组合杂交，看不出性别关联 ✘；
- D：只做一次正交，没有对照 ✘；
- B：正反交互为对照，一眼定乾坤 ✓。

**30 秒锁定 B**——设计实验题先想"**对照组**"在哪。

## 点评

- 伴性遗传（X 染色体）的判断证据链（选填背住）：
  1. 正反交结果不同；
  2. 女患→父必患、子必患（伴 X 隐性交叉遗传）；
  3. 遗传与性别相关（性别比例异常）；
- 变式：若题目已知是隐性性状、判断基因在常染色体还是 X 染色体 → 选**隐性雌 × 显性雄**（"隐雌×显雄"）：子代雌性全为显性、雄性全为隐性 → 伴 X 遗传；子代表现与性别无关 → 常染色体遗传；
- 若正反交结果**只与母本有关**（子代全随母方）→ 细胞质遗传（叶绿体/线粒体基因），与伴 X 区分开（伴 X 不"仅随母方"）；
- 大题书写："选择正反交组合，若两组子代表现型一致则为常染色体遗传，不一致则为伴 X 遗传"——结论要写"若…则…"的完整判断。
