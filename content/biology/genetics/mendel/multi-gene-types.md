# 遗传多对基因·比值变式全表与题眼

两对及以上基因**自由组合**时，后代性状比=两对**各自分离比的乘积**（$(3:1)\times(3:1)=9:3:3:1$），题目的"变式"都是把九个格子**按表现型合并**。这类题不会太为难人：**比数之和一定是 $16$（两对）/$64$（三对）**，题目会留明显提示（"子代中……的比例"），先按提示排除，再用表秒判。

## 两对基因 9:3:3:1 的全部变式（背表）

| 表现型比例 | 基因互作类型 | 说明 |
| --- | --- | --- |
| 9:3:3:1 | 自由组合（无互作） | 双显、单显A、单显B、双隐 |
| 9:7 | 互补作用 | 双显+其余=另一性状：显性互补才显性 |
| 9:6:1 | 累加作用 | 双显、任意单显（同类）、双隐 |
| 9:3:4 | 隐性上位 | 隐同源(B)隐去 A 表现型 |
| 12:3:1 | 显性上位 | 显性 A 抑制 B 的表达 |
| 15:1 | 重叠作用 | 只要有显性即为显性性状 |
| 13:3 | 抑制基因 | 存在抑制基因时全显（13=9+3+1） |
| 1:4:6:4:1 | 数量性状（累加） | AABB：AaBB/AABb：…：aabb 连续分布 |

**口诀**："和为 16 是两对；7 是互补、6 是累加、4 是上位、1 是重叠、3 是抑制；数字越少越'挤'，看'谁压谁'定称呼。"

## 三对及以上的快速处理

- 比数之和 $=64$（$4^3$）→ 三对；一般给"三对独立遗传"关键是**拆开成单对**分别算概率再乘；
- 表现型种类 = 明确可能组合数；如问"纯合子比例"：每对 $\dfrac14$ 相乘；
- **9:6:1 变体**（如 27:37）不背，直接按"双显/单显/双隐"字典合并。

## 题眼总结（题干里常见提示词）

1. **"自由组合"** 或 **"位于非同源染色体上"** → 每对独立，比例相乘；
2. **"某比例 ≈ 16 份"** → 两对，9:3:3:1 系；
3. **"只有 A_B_ 才……"** → 互补型（9:7）；
4. **"显性 A 抑制 B"** → 显性上位（12:3:1）；
5. **"隐性纯合隐去……"** → 隐性上位（9:3:4）；
6. **"只要有显性基因即……"** → 重叠型（15:1）；
7. **"每多一个显性基因，性状增强一档"** → 数量性状：按**显性等位基因数**分档，$\left(\dfrac12+\dfrac12\right)^{2n}$ 展开（$n$ 对基因），如 $n=2$ 时 $1:4:6:4:1$；
8. **子代全是显性但比例不是 9:3:3:1**（如 9:6:1 里问"某表现型比例"）→ 先定表现型归类再数格子；
9. **给"纯合×纯合，F2 比 XX"** 直接对表；给"测交比"（$1:1:1:1$ = 无互作；$1:3$ = 互补；$3:1$ = 某上位…）**测交比 = 变式比 ÷9 或 ÷3 类**：13:3 测交 3:1；9:7 测交 1:3。

## 怎么用（三步）

1. **读题干锁定"16 份"** → 默认两对自由组合，写出亲本 $AaBb\times AaBb$；
2. **对表定类型** → 找出"谁与谁同表现型"（把 9:3:3:1 的四个格子按题目描述合并）；
3. **只算被问的那一档** → 用分子计数：如 9:6:1 中"双显"=9/16，问 "仅一个显性" = 6/16 = 3/8——注意"恰好一个显性基因 ≠ 单显纯合"，A_bb + aaB_ 才是"任意单显"。

## 风险

- 别把"基因自由组合"误当"基因连锁"：连锁时比例不是 16 份（出现亲本型比例高）；
- 9:6:1 累加作用里 6 是两个"单显"合并，**写"33:31"那种小比例**必先分母化成 64 判断是否三对；
- 测交比与自交比混淆：$AaBb\times aabb$ 测交为 $1:1:1:1$（无互作）/ $1:3$（互补）/ $1:2:1$（累加）——测交比对应的是**配子组合表现型**，表里写的是自交比，别混。
- 数量性状答案可能是**区间/连续值**；"1:4:6:4:1"只适用纯合双亲 AABB × aabb，若 F1 自交前有杂合则变体。
