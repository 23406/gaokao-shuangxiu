# 生物技术与工程

## 微生物的培养与应用

- 培养基成分：碳源、氮源、水、无机盐（+特殊需求：维生素）；
- 无菌技术：灭菌（杀死一切微生物：灼烧/干热/高压蒸汽）、消毒（杀死部分：煮沸/巴氏）；
- 接种方法：平板划线法（分离纯化）、稀释涂布平板法（**计数**）；
- 菌落计数：统计的活菌数**比实际少**（两个以上菌体可能连在一起形成一个菌落）；
- 选择培养基 vs 鉴别培养基（伊红美蓝鉴别大肠杆菌，黑色菌落）。

## 发酵工程（传统发酵技术）

- 果酒：酵母菌（无氧发酵产酒精）；果醋：醋酸菌（有氧）；
- 腐乳：毛霉等微生物；泡菜：乳酸菌（无氧，坛口密封）；
- 发酵工程流程：菌种选育 → 扩大培养 → 接种 → 发酵罐发酵 → 提取产品；
- 消毒灭菌关键点：果酒发酵前**清洗葡萄不能反复冲洗**（保留野生酵母）。

## 基因工程（回顾 + 应用）

- 工具：限制酶、DNA 连接酶、运载体（质粒等）；
- 四步：目的基因获取 → 表达载体构建 → 导入受体 → 检测鉴定；
- 应用：转基因作物（抗虫棉）、基因药物（胰岛素）、基因治疗；
- PCR 技术：体外 DNA 扩增（引物、耐高温 DNA 聚合酶 Taq 酶）。

## 细胞工程

- 植物组织培养：原理**细胞全能性**，条件无菌+激素（生长素/细胞分裂素配比）；
- 植物体细胞杂交：去壁（纤维素酶果胶酶）→ 融合（物理/化学：PEG）→ 杂种细胞 → 组织培养；
- 动物细胞培养：原理细胞增殖；条件：营养物质+血清+$CO_2$ 培养箱（维持 pH）；
- 动物细胞融合（杂交瘤技术）：骨髓瘤细胞 + B 淋巴细胞 → 杂交瘤细胞 → **单克隆抗体**（特异性强灵敏度高）；
- 动物细胞核移植：克隆（多莉羊）。

## 胚胎工程

- 体外受精：获能精子 + 成熟卵母细胞；
- 胚胎移植：供体（超数排卵）→ 受体（同期发情处理）；
- 胚胎分割：同卵双胞胎（遗传物质相同）。

## 邪修提示

- 菌落计数："涂布平板法统计值偏小"是永恒考点；
- 单克隆抗体：杂交瘤细胞兼具"骨髓瘤细胞无限增殖 + B 细胞分泌抗体"两个优点；
- 果酒果醋顺序：先酒后醋（先无氧后有氧），温度不同（18~25°C vs 30~35°C）；
- 风险：动物细胞培养**不能**用组织培养的"全能性"表述（动物细胞核才有全能性）；"基因工程的核心步骤"是**表达载体构建**。
