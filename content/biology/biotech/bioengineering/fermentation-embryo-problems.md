# 发酵工程与胚胎工程选填速练

> 配套概念卡见 [生物技术与工程](biotech.md)；单克隆抗体专项见 [单克隆抗体制备流程](hybridoma.md)。

## 细节速查（选择题直接对应）

| 考点 | 标准表述 | 常见鱼钩 |
|---|---|---|
| 果酒 | 酵母菌**无氧**产酒精，18~25℃；清洗葡萄**不能反复冲洗**（保野生酵母） | "反复冲洗更干净" ❌ |
| 果醋 | 醋酸菌**有氧**；30~35℃；先酒后醋 | "果醋不需氧气" ❌ |
| 泡菜 | 乳酸菌（厌氧），坛密封；亚硝酸盐含量**先升后降** | "一直在升高" ❌ |
| 亚硝酸盐检测 | **比色法**（显色后与标准显色液比色） | 与"显微镜计数"混 ❌ |
| 菌落计数 | 稀释涂布平板法；选**30~300** 个菌落平板；统计值**偏小** | "选 300 以上" ❌ / "统计准确" ❌ |
| 胚胎移植 | 供体**超数排卵**；受体**同期发情**；移植胚胎发育到**桑椹胚或囊胚**；是胚胎工程**最后一步** | "受体也超数排卵" ❌ |
| 胚胎分割 | 同卵（遗传物质**相同**）；囊胚段分割需**均等分割内细胞团** | "遗传物质改变" ❌ |

## 题目

（1）**泡菜与亚硝酸盐**。关于泡菜制作与检测，下列叙述正确的是（ ）

A. 亚硝酸盐含量随腌制时间延长持续升高

B. 泡菜坛中乳酸菌在有氧条件下大量繁殖，抑制杂菌生长

C. 可用比色法估测泡菜中亚硝酸盐含量

D. 亚硝酸盐与其中的胺类反应只能在碱性条件下生成致癌物亚硝胺

（2）**果酒果醋**。关于果酒与果醋的制备，下列叙述正确的有（ ）

A. 制作果酒时需先通入无菌空气使酵母菌大量繁殖，再密闭发酵

B. 酒精发酵温度一般应高于醋酸发酵温度

C. 醋酸菌将酒精氧化为乙酸的中间产物是乙醛

D. 果酒制作中，发酵液出现气泡即表示酒精发酵停止

（3）**微生物计数**。用稀释涂布平板法测定微生物数量，下列叙述正确的是（ ）

A. 统计结果可能比实际活菌数偏大

B. 应选择菌落数大于 300 的平板进行计数

C. 计数的依据是"每个菌落来源于一个活菌"

D. 每个浓度至少接种 2 个平板，以减少偶然误差

（4）**胚胎移植与分割**。关于哺乳动物胚胎工程，下列叙述**错误**的是（ ）

A. 供体母牛的卵母细胞在体外受精前一般要培养到 MⅡ期

B. 受体母牛须进行超数排卵处理，以提高移植成功概率

C. 胚胎移植是胚胎工程的最后一步

D. 胚胎分割得到的两个后代遗传物质相同

## 标准解法

### （1）泡菜与亚硝酸盐

A 错：亚硝酸盐含量在腌制初期升高、**后期下降**（乳酸积累抑制产亚硝酸盐的杂菌，教材曲线"先升后降"）。

B 错：乳酸菌是**厌氧**菌，坛内密封创造**无氧**环境使其成为优势菌。

C 对：亚硝酸盐与对氨基苯磺酸、N-1-萘基乙二胺盐酸盐反应显色，与标准液**比色**定量（比色法）。

D 错：亚硝酸盐在**酸性**条件下与胺类反应生成亚硝胺（致癌），碱性条件不利。

**答 C**。

### （2）果酒果醋

A 对：**工业发酵罐**先通气（酵母菌有氧增殖）后密闭（无氧产酒精）；家庭简易制作通常直接密封。

B 错：酒精发酵 18~25℃，醋酸发酵 30~35℃，后者**更高**。

C 对：醋酸菌氧化酒精：乙醇 $\to$ 乙醛 $\to$ 乙酸（两步）。

D 错：酵母菌有氧呼吸也产生 $CO_2$；气泡消失（或耗糖殆尽）才是停止。

**答 A、C**。

### （3）微生物计数

A 错：两个以上菌体可能连成一个菌落 → 统计值**偏小**（漏计）。

B 错：选 **30~300** 个菌落的平板（过少无意义、过多难分辨且营养重叠）。

C 对：前提假设"一个菌落来源于一个活菌"——这正是"偏小"的来源。

D 对：重复实验减小偶然误差（教材用 3 个平板取平均）。

**答 C、D**。

### （4）胚胎移植与分割

A 对：卵母细胞发育到 **MⅡ期**（减数第二次分裂中期）才具有受精能力。

B 错：**超数排卵针对供体母牛**（注射促性腺激素）；受体只需**同期发情处理**（创造相同生理状态），二者不可互换。

C 对：体外受精 → 早期胚胎培养 → **胚胎移植（最后一步）** → 移植后检查。

D 对：胚胎分割属无性繁殖，子代遗传物质相同（同卵双生）。

**答 B**。

## 邪修解法

**四句口诀四张牌**（选填秒出）：

1. **泡菜**：厌氧乳酸菌 + 密封 + 亚硝酸盐"先升后降" + **比色法**测——出现"持续升高""有氧"直接叉；
2. **酒醋**：酒 18~25℃ 无氧、醋 30~35℃ 有氧，**先酒后醋**——"温度更高"选醋酸、"需要氧气"选醋酸；
3. **计数**：30~300 + 统计值**偏小** + 一个菌落 = 一个活菌——出现"偏大"即叉；显微镜直接计数偏**大**（不分死活），与涂布法相反；
4. **胚胎**：**供体超排、受体同期**（动词绑死互换即错）+ 桑椹/囊胚 + 均分内细胞团——出现"受体超排""DNA 改变"即叉。

> 易混三连：亚硝酸盐**比色**、菌落**计数**（涂布平板 30~300 偏小）、胚胎**移植**（供体超排受体同期）——三张牌各管一件事，混了就是丢分点。

## 点评

- **泡菜本质**：乳酸菌发酵 = 无氧呼吸产乳酸；亚硝酸盐是"硝酸盐还原菌"的代谢产物，后期被乳酸环境抑制就下降（所以**腌制时间要足够**才安全）；
- **酒醋顺序**：先酒精后醋酸——酒精发酵结束再开盖供氧，醋酸菌才开工；若同时供氧，酒精菌竞争不过,产率低；
- **计数系统**：涂布平板法 = 活菌计数但偏小；显微镜直接计数 = 全部细胞但偏大；血球计数板（血红/酵母菌用）计数的是"总数"不是"活菌数"；
- **胚胎工程对比**：供体（提供卵、超排、注射促性腺激素）vs 受体（代孕、同期发情、不注射促性腺激素）；胚胎分割"均分内细胞团"保证发育协调——这部分在 biotech.md 概念卡里都有，本文件是"判断训练"；
- **迁移**："先酒后醋"与"先氧后密"分别对应家庭式与工业式发酵；题目给"葡萄酒生产流程"时注意看清是哪种。
