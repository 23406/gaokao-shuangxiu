# 群落与生态系统

## 群落

- 群落 = 一定区域内**所有种群**的总和（物种组成是重要特征，丰富度 = 物种数）；
- 种间关系：捕食、竞争、寄生、互利共生（曲线图识别：捕食"先增后减交替"、竞争"你死我活"）；
- 群落演替：初生演替（裸岩→地衣→苔藓→草本→灌木→乔木，从无到有）；次生演替（弃耕农田→杂草→灌木→乔木，原有土壤条件保留，**速度更快**）；
- 人类活动可改变演替**方向和速度**。

## 生态系统的结构

- 组成：非生物的物质和能量 + 生产者（基石，自养）+ 消费者（异养）+ 分解者（腐生，必不可少）；
- 营养结构：食物链/食物网（**只有生产者和消费者**，分解者不占营养级）；
- 食物链起点必须是生产者，终点是最高营养级（不被捕食）。

## 能量流动

- 起点：生产者固定太阳能；渠道：食物链/网；
- 特点：**单向流动、逐级递减**（传递效率 10%~20%）；
- 摄入量 = 同化量 + 粪便量（粪便属于**上一营养级**的能量！）；
- 同化量 = 呼吸消耗 + 用于生长发育繁殖 = 呼吸 + 流向下一级 + 流向分解者 + 未利用；
- 意义：帮助人们合理调整能量流动关系，使能量**持续高效**地流向对人类最有益的部分。

## 物质循环（碳循环）

- 形式：$CO_2$（大气↔生物群落，主要形式）；有机物（生物群落内部）；
- 过程：光合/化能合成（进群落）→ 呼吸/分解/燃烧（出群落）；
- 特点：**全球性、循环往复**；
- 温室效应：化石燃料燃烧 + 植被破坏 → $CO_2$ 平衡被打破。

## 信息传递与稳定性

- 类型：物理信息（光声温度）、化学信息（化学物质：性外激素）、行为信息（蜜蜂跳舞）；
- 功能：生命活动正常进行、种群繁衍、调节种间关系维持生态平衡；
- 应用：信息素诱捕（生物防治，无污染）；
- 稳定性：抵抗力稳定性（组分越多营养结构越复杂越强）与恢复力稳定性（**通常**负相关）；
- 自我调节能力的基础：**负反馈调节**（有限度的）。

## 邪修提示

- 能量计算：**"10%~20% 传递"正向算乘、反向算除**，选填 20% 上限直接估算；
- 粪便能量归属：**粪便不是自己的同化量**，是上一营养级的——经典陷阱；
- 食物链判断：看箭头方向（能量流向），分解者/非生物物质不画进食物链；
- 风险：生态系统能量**单向**不循环，物质**循环**不单向——"能量流动和物质循环"别混。
